### BE-02 页面注册表与生效值服务（P1）

- 新文件：`app/services/page_switches.py`。
- 内容：
  - `PAGE_REGISTRY`：71 个路径 → `{module, is_tab, allow_disable}`，路径清单与 pages.json 2026-11-16 快照一致（7 主包 + 64 分包）。
  - **恒开锚点页（allow_disable=False）**：`pages/auth/login`、`pages/auth/register`、`pages/index/index`（首页为前端守卫 reLaunch 锚点，交叉验证新增）。
  - `effective_page_switches(db) -> dict`：经 `runtime_config.load_config`（runtime_config.py:20，异常返回 {}）读快照；生效值 = `modules[模块] AND pages[路径]`；缺键/异常一律回退 True（fail-open）；锚点页恒 True。**生效值只在后端计算**，前端不复制与/或逻辑。
  - 进程内 TTL 缓存 30 秒；DB 异常保留上次缓存；缓存未初始化返回全开默认。
  - `tab_paths()`：返回 5 个 tab 路径常量（与 pages.json tabBar.list 一致）。
- 模块归属：ai（search、my-portrait-master/result/archive、my-ai-avatar）；emotion_lab（1）；community（社区 10 页）；paper_plane（纸飞机 4 页）；matchmaker（13）；membership（vip、unlock-history、my-date-service 等）；parent（2）；profile_tools（其余 profileExtra）；chat（chat/detail）；system（其余 tab 4 页、settings/security/help/about/userExtra 等）。
- 口径：`chat/detail` 页面开关只控聊天页整体；AI 模式可用性仍由 `/ai/capabilities` 判定（detail.uvue:553 mode 分支），不用页面开关杀普通聊天。
- 验收：单测覆盖默认全开/模块关/页面覆盖/缺键 fail-open/锚点恒开。

### BE-03 匿名下发接口（P1）

- 新文件：`app/api/routes/public_page_switches.py`（`APIRouter(prefix="/public")`，仿 routes/public_preview.py:20）；schema 新文件 `app/schemas/public_page_switches.py`。
- 挂载：`app/api/router.py` 在 public_preview 挂载点（147 行）旁 `include_router(public_page_switches.router, tags=["游客预览"])`。
- 路由：`GET /api/v1/public/page-switches`，匿名（无鉴权依赖），入参仅 `Request`（取 IP）+ `db`。
- 限流：复用 `app/core/redis.py:264 consume_rate_limit(key, limit, window_seconds)`，key `public:page-switches:{ip}`，30 次/60 秒；IP 取 `routes/auth.request_ip`（与游客预览同源）。超限 429，结构仿 `PUBLIC_PREVIEW_RATE_LIMITED`（public_preview.py:65-73），code `PUBLIC_PAGE_SWITCHES_RATE_LIMITED`。
- 响应模型 `PublicPageSwitchesResponse`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| version | int | `platform_page_switches` 快照 version，供前端缓存比对 |
| modules | object[str,bool] | 10 个模块开关原始值 |
| pages | object[str,bool] | 71 路径**生效值**（模块 AND 页面，锚点恒 true） |
| tabs | array[str] | 5 个 tab 路径（前端 XsaTabBar 过滤用） |
| placeholder_text | str | 占位文案 |
| operation | object | registration_enabled / browse_enabled（复用 `platform_registration_open/platform_browse_open`，runtime_config.py:75-88）+ maintenance_message |
| ai | object | master/profile/search/compatibility/voice/advisor/avatar 公开基准位 |

- `ai` 公开位计算：在 `app/services/ai/flags.py` 暴露公开 helper（复用 `is_ai_feature_enabled` + `_production_approvals_ok`，**不含** `ai_test_only_user_ids` 用户范围检查），供本接口与文档引用；不复制判定逻辑。登录用户权威判定仍是 `/ai/capabilities`（现有接口零改动）。
- 本接口处理前先 `await runtime_gates.maybe_refresh(db)`（BE-04），保证 ai 公开位含最新 kill 状态。
- 错误契约：429 限流；配置表不可用**不报错**，返回全开默认 + 默认文案（fail-open）。文档注明前端应静默处理、不弹 loading/toast。
- 验收：匿名 200；第 31 次/分钟 429；关模块后 pages 生效值随动；断 DB 返回默认全开。

### BE-04 AI 运行时关停层（P1，核心应急通道）

- 新文件：`app/services/ai/runtime_gates.py`：
  - `maybe_refresh(db)`：TTL 30 秒到期才经 `load_config(db, "ai_runtime")` 读快照进进程缓存；DB 异常保留旧缓存；未初始化视为无 kill（env 门禁照常）。
  - `is_killed(feature: AiFeature) -> bool`：同步读缓存；`master_kill=true` 时所有 feature 视为 killed；feature→kill 键映射与 `AiFeature` 枚举一一对应（flags.py:18-34）。
- 改动点仅 2 处（不动 19 个 `require_ai_feature` 调用点）：
  1. `app/services/ai/flags.py:110 require_ai_feature` 入口追加：`if is_killed(feature): raise AiFeatureDisabledError(feature)`。**kill 只能关死，不能打开 env/审批门关闭的功能**（安全方向与现有 fail-closed 一致；生产审批门检查顺序不变）。
  2. `app/main.py` 新增 `@application.middleware("http")`（仿 153/209 行既有模式）：路径命中 `settings.api_prefix + "/ai/"` 或 `"/voice"` 前缀时 `await maybe_refresh(db)`（TTL 内零 DB 开销；db 会话经 `get_db` 同款依赖获取，注意中间件内自建短会话并关闭）。`/ai/capabilities` 路由与 BE-03 接口内各显式刷新一次兜底。
- 生效时延：管理端 PATCH 后 ≤30 秒/实例（多 worker 各自 TTL）；叠加前端节流后端到端 ≤90 秒（下次 onShow）。
- 应急操作：`PATCH /admin/configs/ai_runtime` 置 `master_kill=true` → 8 功能位全 false、AI 接口 503 `AI_FEATURE_DISABLED`、`/ai/capabilities` 自动随动（前端已接线三页零改动受益）；改回 false 恢复。
- 验收：见 BE-05 测试清单；测试服先演练再上生产。
