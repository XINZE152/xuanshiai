# 配置消费改造：接线清单与逐配置项审计（2026-09-09）

> 目标：让「平台配置 / 系统管理 / 财务管理」管理端保存的配置**真正被后端运行时代码消费**。
> 原则：凡接入的配置，**默认值与当前后端行为一致**；只有管理员在后台明确改动后行为才改变；
> 后端没有对应功能/数据模型的配置项不强行虚构消费点，而是如实标注缺什么、在哪接。

### 3.5 platform_register_guide 信息登记引导页
rows ⭕。注册引导页目前是客户端流程（后端 auth 仅有手机号验证码建号，无引导页字段）。接法：新增“登记引导页配置下发”并在 App 注册引导页读取。

### 3.6 platform_register_fields 基本资料登记
subtitle/fields ⭕。登记字段由客户端表单决定。接法：下发字段配置驱动客户端表单顺序/开关。

### 3.7 platform_private_fields 私密信息登记与展示
rows ⭕。私密资料字段与展示开关无对应后端模型（voice/房车等资料模型缺失）。接法：待资料模型补齐后，字段可见性在 `view_profile`/`get_profile` 中按配置裁剪。

### 3.8 platform_filter_config 筛选功能配置
rows ⭕。筛选条件选项目前来自 `core/profile_tags.py` 常量 + `get_filter_options()`。接法：`get_filter_options` 改为“常量 ∪ 本域配置覆盖”后即可生效。
