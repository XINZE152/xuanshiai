# 社区运营与消息后台接口

更新时间：2026-08-24

本文档覆盖本轮新增挂载的社区话题/Banner 后台和消息后台接口。接口前缀为 `/api/v1`，均使用红娘后台独立 Bearer Token，并通过 `get_current_matchmaker_admin` 校验权限。

## 通用约定

| Header | 必填 | 说明 | 示例 |
|---|---:|---|---|
| `Authorization` | 是 | 红娘后台 Bearer Token | `Bearer <token>` |
| `Content-Type` | 有请求体时是 | JSON 请求 | `application/json` |

权限规则：

- 社区后台 GET：需要 `community.read`、`community.moderate` 或 `*`。
- 社区话题/Banner 写操作：除需要 `community.moderate` 外，当前仅允许 `data_scope=ALL` 或 `*` 权限账号。
- 消息后台 GET：需要 `message.read`、`message.manage`、`message.moderate` 或 `*`。
- 消息处置和公告创建：需要 `message.manage`、`message.moderate` 或 `*`。
- 消息查询和处置根据 `SELF/STORE/ORGANIZATION/ALL` 范围过滤；公告创建当前仅允许全局范围管理员。

通用错误：`401` 未登录或 Token 失效；`403` 权限或范围不足；`404` 资源不存在或不在数据范围；`409` 名称冲突；`422` 参数非法；`503` 数据库暂时不可用。

#### 查询社区话题配置

**基本信息**：完整 URL `GET /api/v1/admin/community/topics`；需要登录和社区读取权限；无请求体；成功状态码 `200`。

**请求参数**：无 Path、Query 或 Body 参数。

**请求体示例**：

```http
GET /api/v1/admin/community/topics
Authorization: Bearer <token>
```

无请求体。非法示例：缺少 `Authorization`，返回 `401`。

**返回参数**：数组元素包含 `id/name/icon/sort/is_active/post_count/participant_count/heat/joined/created_at`。`post_count` 为有效动态数，`participant_count` 为参与用户数，`heat` 当前为两者之和，`joined` 对后台固定为 `false`。

**返回示例**：

```json
[
  {
    "id": 1,
    "name": "周末活动",
    "icon": "/storage/uploads/topic.png",
    "sort": 100,
    "is_active": true,
    "post_count": 20,
    "participant_count": 15,
    "heat": 35,
    "joined": false,
    "created_at": "2026-08-24T10:00:00"
  }
]
```

**使用方法与业务规则**：按 `sort DESC, id DESC` 排序；当前话题是平台级配置，不做组织级隔离。

**错误**：`401`、`403`、`503`。

#### 创建社区话题

**基本信息**：完整 URL `POST /api/v1/admin/community/topics`；需要社区写权限和全局数据范围；Content-Type `application/json`；成功状态码 `201`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验 | 含义 | 合法示例 | 非法示例 |
|---|---|---|---:|---|---|---|---|---|
| `name` | body | string | 是 | 无 | 1～64 字符，名称唯一 | 话题名称 | `周末活动` | 空字符串 |
| `icon` | body | string/null | 否 | `null` | 最长 255 | 图标地址 | `/storage/uploads/a.png` | 超长地址 |
| `sort` | body | integer | 否 | `0` | -100000～100000 | 排序值 | `100` | `200000` |
| `is_active` | body | boolean | 否 | `true` | 布尔值 | 是否启用 | `true` | `1` 字符串 |

**请求体示例**：

```json
{"name":"周末活动","icon":"/storage/uploads/a.png","sort":100,"is_active":true}
```

非法示例：同名话题返回 `409`。

**返回参数**：同“查询社区话题配置”的单个数组元素。

**返回示例**：

```json
{"id":1,"name":"周末活动","icon":"/storage/uploads/a.png","sort":100,"is_active":true,"post_count":0,"participant_count":0,"heat":0,"joined":false,"created_at":"2026-08-24T10:00:00"}
```

**使用方法与业务规则**：创建成功后写入 `business_audit_log`，保存创建后快照；当前不支持客户端幂等键，前端提交时需防重复点击。

**错误**：`401`、`403`、`409`、`422`、`503`。

#### 更新社区话题

**基本信息**：完整 URL `PATCH /api/v1/admin/community/topics/{topic_id}`；需要社区写权限和全局数据范围；成功状态码 `200`。

**请求参数**：`topic_id` 位于 Path，正整数且话题必须存在；Body 字段与创建接口一致，当前为完整覆盖更新。

**请求体示例**：

```http
PATCH /api/v1/admin/community/topics/1
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{"name":"本周活动","icon":null,"sort":120,"is_active":true}
```

非法示例：`topic_id=0` 返回 `422`；不存在返回 `404`；其他话题同名返回 `409`。

**返回参数/返回示例**：同创建接口。

**使用方法与业务规则**：使用行锁读取旧数据，更新后写入包含前后快照的审计日志。

**错误**：`401`、`403`、`404`、`409`、`422`、`503`。

#### 查询社区 Banner 配置

**基本信息**：完整 URL `GET /api/v1/admin/community/banners`；需要社区读取权限；成功状态码 `200`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验 | 含义 | 示例 |
|---|---|---|---:|---|---|---|---|
| `position` | query | string/null | 否 | `null` | 最长 32 | 按位置过滤 | `community` |

**请求体示例**：无请求体。

```http
GET /api/v1/admin/community/banners?position=community
Authorization: Bearer <token>
```

非法示例：超过 32 字符返回 `422`。

**返回参数**：数组元素包含 `id/title/image_url/link_type/link_value/sort/position/is_active/start_at/end_at`。

**返回示例**：

```json
[{"id":1,"title":"活动入口","image_url":"/storage/uploads/banner.png","link_type":"activity","link_value":"12","sort":100,"position":"community","is_active":true,"start_at":null,"end_at":null}]
```

**使用方法与业务规则**：返回后台全部状态配置，不自动过滤未生效时间段。

**错误**：`401`、`403`、`422`、`503`。

#### 创建社区 Banner

**基本信息**：完整 URL `POST /api/v1/admin/community/banners`；需要社区写权限和全局数据范围；成功状态码 `201`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验和含义 |
|---|---|---|---:|---|---|
| `title` | body | string/null | 否 | `null` | 最长 128 |
| `image_url` | body | string | 是 | 无 | 1～255，Banner 图片地址 |
| `link_type` | body | string | 否 | `none` | `activity/url/miniprogram/none` |
| `link_value` | body | string/null | 否 | `null` | `none` 时必须为空，其他类型必须提供 |
| `sort` | body | integer | 否 | `0` | -100000～100000 |
| `position` | body | string | 否 | `community` | 1～32 |
| `is_active` | body | boolean | 否 | `true` | 是否启用 |
| `start_at` | body | datetime/null | 否 | `null` | 生效开始时间 |
| `end_at` | body | datetime/null | 否 | `null` | 必须晚于 `start_at` |

**请求体示例**：

```json
{"title":"活动入口","image_url":"/storage/uploads/banner.png","link_type":"activity","link_value":"12","sort":100,"position":"community","is_active":true,"start_at":null,"end_at":null}
```

非法示例：`link_type=none` 却提供 `link_value`，或 `end_at<=start_at`，返回 `422`。

**返回参数/返回示例**：同查询接口中的单个元素。

**使用方法与业务规则**：写入创建后审计快照；当前未实现同一位置和时间段的 Banner 发布冲突限制，该项仍在修改清单中。

**错误**：`401`、`403`、`422`、`503`。

#### 更新社区 Banner

**基本信息**：完整 URL `PATCH /api/v1/admin/community/banners/{banner_id}`；需要社区写权限和全局数据范围；成功状态码 `200`。

**请求参数**：`banner_id` 为正整数；Body 与创建接口相同，当前为完整覆盖更新。

非法示例：不存在的 ID 返回 `404`。

**返回参数/返回示例**：同查询接口中的单个元素。

**使用方法与业务规则**：使用行锁读取旧数据，审计日志保存前后快照。

**错误**：`401`、`403`、`404`、`422`、`503`。

#### 分页查询聊天消息

**基本信息**：完整 URL `GET /api/v1/admin/messages`；需要消息读取权限；成功状态码 `200`；无请求体。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验 | 含义 |
|---|---|---|---:|---|---|---|
| `page` | query | integer | 否 | `1` | `>=1` | 页码 |
| `page_size` | query | integer | 否 | `20` | 1～100 | 每页数量 |
| `user_id` | query | integer/null | 否 | `null` | 正整数 | 筛选发送方或接收方 |
| `session_id` | query | integer/null | 否 | `null` | 正整数 | 筛选聊天会话 |
| `message_type` | query | integer/null | 否 | `null` | 1～6 | 筛选消息类型 |

**请求体示例**：无请求体。

```http
GET /api/v1/admin/messages?page=1&page_size=20&user_id=100
Authorization: Bearer <token>
```

非法示例：`page=0` 或 `page_size=101` 返回 `422`。

**返回参数**：

| 字段 | 类型 | 必返 | 含义 |
|---|---|---:|---|
| `items` | array | 是 | 消息数组 |
| `items[].id` | integer | 是 | 消息 ID |
| `items[].session_id` | integer | 是 | 会话 ID |
| `items[].from_user_id/to_user_id` | integer | 是 | 双方用户 ID |
| `items[].type` | integer | 是 | 消息类型 |
| `items[].content` | string/null | 是 | 文本内容；手机号会脱敏 |
| `items[].media_url` | string/null | 是 | 媒体地址 |
| `items[].is_read` | boolean | 是 | 是否已读 |
| `items[].revoked_at` | datetime/null | 是 | 撤回时间 |
| `items[].created_at` | datetime | 是 | 创建时间 |
| `page/page_size/total/has_more` | integer/boolean | 是 | 分页信息 |

**返回示例**：

```json
{"items":[{"id":1,"session_id":10,"from_user_id":100,"to_user_id":200,"type":1,"content":"联系电话1**********","media_url":null,"is_read":false,"revoked_at":null,"created_at":"2026-08-24T10:00:00"}],"page":1,"page_size":20,"total":1,"has_more":false}
```

**使用方法与业务规则**：根据管理员数据范围查询：SELF 仅查看归属本人红娘的会员消息；STORE/ORGANIZATION 查看本组织资源归属会员消息；ALL 查看全部。普通响应对大陆手机号进行脱敏，不提供导出接口。

**错误**：`401`、`403`、`422`、`503`。

#### 处置聊天消息

**基本信息**：完整 URL `PATCH /api/v1/admin/messages/{message_id}/moderation`；需要消息管理权限；成功状态码 `200`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 校验 | 含义 |
|---|---|---|---:|---|---|
| `message_id` | path | integer | 是 | 正整数且在当前数据范围 | 消息 ID |
| `action` | body | string | 是 | `recall/restore` | 管理撤回或恢复 |
| `reason` | body | string | 是 | 1～255 | 处置原因 |

**请求体示例**：

```json
{"action":"recall","reason":"用户举报后确认包含骚扰内容"}
```

非法示例：`action=delete` 返回 `422`；越权资源按 `404` 返回，避免泄露存在性。

**返回参数/返回示例**：返回处置后的 `AdminMessageItem`，内容中的手机号脱敏。

```json
{"id":1,"session_id":10,"from_user_id":100,"to_user_id":200,"type":1,"content":"已脱敏内容","media_url":null,"is_read":false,"revoked_at":"2026-08-24T10:10:00","created_at":"2026-08-24T10:00:00"}
```

**使用方法与业务规则**：使用行锁读取消息；审计日志保存处置前后快照、操作者和原因；快照中的手机号同样脱敏。当前只支持撤回和恢复，不物理删除消息。

**错误**：`401`、`403`、`404`、`422`、`503`。

#### 创建管理端公告

**基本信息**：完整 URL `POST /api/v1/admin/messages/announcements`；需要消息管理权限和全局数据范围；成功状态码 `201`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验 | 含义 |
|---|---|---|---:|---|---|---|
| `category` | body | string | 是 | 无 | 1～64 | 公告分类 |
| `title` | body | string | 是 | 无 | 1～255 | 公告标题 |
| `link_to` | body | string/null | 否 | `null` | 最长 500 | 跳转地址 |
| `published_at` | body | datetime/null | 否 | `null` | ISO 8601 | 发布时间；空值表示未发布草稿 |

**请求体示例**：

```json
{"category":"版本更新","title":"2026-08-24 更新说明","link_to":"/pages/announcement/1","published_at":"2026-08-24T12:00:00"}
```

非法示例：非全局管理员返回 `403`；空标题返回 `422`。

**返回参数**：`id/category/title/link_to/published_at/created_at`。

**返回示例**：

```json
{"id":1,"category":"版本更新","title":"2026-08-24 更新说明","link_to":"/pages/announcement/1","published_at":"2026-08-24T12:00:00","created_at":"2026-08-24T11:00:00"}
```

**使用方法与业务规则**：写入 `tenant_id=1`；创建后记录审计快照。当前未实现公告更新、下线、版本关联和定时任务，不能认定完整公告运营闭环完成。

**错误**：`401`、`403`、`422`、`503`。
