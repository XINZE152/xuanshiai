#### 会员推荐名单查询与手工添加

本组接口用于红娘在会员 CRM 中查看某会员已经加入的推荐名单，并从 CRM 搜索结果中手工添加新的推荐会员。

## 1. 查询已添加推荐名单

**基本信息**：`GET /api/v1/admin/members/{member_id}/recommend-history`，需要红娘后台登录和 `matchmaker.member.read` 权限；无请求体；响应 `application/json`；成功状态码 `200`。

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验/示例 | 含义 |
| --- | --- | --- | --- | --- | --- | --- |
| `member_id` | path | integer | 是 | 无 | `>=1`，如 `101` | 接收推荐的会员 ID |
| `page` | query | integer | 否 | `1` | `1-1000` | 页码 |
| `page_size` | query | integer | 否 | `20` | `1-100` | 每页条数 |

请求示例：

```http
GET /api/v1/admin/members/101/recommend-history?page=1&page_size=20 HTTP/1.1
Authorization: Bearer <matchmaker_admin_access_token>
```

非法示例：`/recommend-history?page=0`，返回 `422`。

### 返回参数

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `items` | array | 是 | 推荐记录；无数据时为 `[]` |
| `items[].id` | integer | 是 | 推荐记录 ID |
| `items[].recommend_date` | date | 是 | 推荐日期 |
| `items[].match_score` | number | 是 | 匹配分；手工添加固定为 `0` |
| `items[].match_reason` | string/null | 是 | 推荐理由；未填写时为 `null` |
| `items[].recommend_source` | string | 是 | 来源，手工添加为 `manual` |
| `items[].is_viewed` | boolean | 是 | 接收会员是否查看 |
| `items[].is_liked` | boolean | 是 | 接收会员是否喜欢 |
| `items[].is_passed` | boolean | 是 | 接收会员是否跳过 |
| `items[].created_at` | datetime/null | 是 | 创建时间 |
| `items[].target_user_id` | integer/null | 是 | 被推荐会员 ID；会员被删除时为 `null` |
| `items[].target_nickname` | string/null | 是 | 被推荐会员昵称 |
| `items[].target_avatar` | string/null | 是 | 被推荐会员头像地址 |
| `page` | integer | 是 | 当前页 |
| `page_size` | integer | 是 | 每页条数 |
| `total` | integer | 是 | 总记录数 |
| `has_more` | boolean | 是 | 是否还有下一页 |

成功响应示例：

```json
{"items":[{"id":88,"recommend_date":"2026-09-20","match_score":0,"match_reason":"兴趣和城市匹配","recommend_source":"manual","is_viewed":false,"is_liked":false,"is_passed":false,"created_at":"2026-09-20T10:00:00","target_user_id":202,"target_nickname":"李四","target_avatar":"https://cdn.example.com/avatar/202.jpg"}],"page":1,"page_size":20,"total":1,"has_more":false}
```

## 2. 手工添加推荐名单

**基本信息**：`POST /api/v1/admin/members/{member_id}/recommendations`，需要红娘后台登录和 `matchmaker.member.manage` 权限；请求/响应 `application/json`；成功状态码 `201`。

### 请求参数与请求体

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验/示例 | 含义 |
| --- | --- | --- | --- | --- | --- | --- |
| `member_id` | path | integer | 是 | 无 | `>=1`，如 `101` | 接收推荐的会员 ID |
| `recommend_user_id` | body | integer | 是 | 无 | `>=1`，如 `202` | 被推荐会员 ID，不能等于 `member_id` |
| `recommend_date` | body | date | 否 | 当天 | `YYYY-MM-DD` | 推荐归属日期 |
| `match_reason` | body | string/null | 否 | `null` | 最长 255 字符 | 推荐理由 |

前端调用顺序：先调用 `GET /api/v1/admin/matchmaker/members?search=...` 搜索会员，取得目标会员 ID 后调用本接口；添加成功后刷新查询接口。

```http
POST /api/v1/admin/members/101/recommendations HTTP/1.1
Authorization: Bearer <matchmaker_admin_access_token>
Content-Type: application/json
```

```json
{"recommend_user_id":202,"recommend_date":"2026-09-20","match_reason":"兴趣和城市匹配"}
```

非法示例：`{"recommend_user_id":101}`，返回 `422`，因为不能推荐给自己。

### 返回参数

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `id` | integer | 是 | 新建推荐记录 ID |
| `user_id` | integer | 是 | 接收推荐的会员 ID |
| `recommend_user_id` | integer | 是 | 被推荐会员 ID |
| `recommend_date` | date | 是 | 推荐日期 |
| `match_score` | number | 是 | 手工推荐固定为 `0` |
| `match_reason` | string/null | 是 | 推荐理由 |
| `recommend_source` | string | 是 | 固定为 `manual` |
| `created_at` | datetime/null | 是 | 创建时间 |

成功响应示例：

```json
{"id":88,"user_id":101,"recommend_user_id":202,"recommend_date":"2026-09-20","match_score":0,"match_reason":"兴趣和城市匹配","recommend_source":"manual","created_at":"2026-09-20T10:00:00"}
```

## 使用方法与业务规则

- 两个接口均只面向红娘后台，不对普通会员开放；会员不存在返回 `404`。
- 查询按推荐日期、记录 ID 倒序分页；空结果返回标准分页结构和 `items: []`。
- 添加接口不扣减会员次数、不创建牵线关系；相同接收会员、被推荐会员、推荐日期重复提交返回 `409`。
- 添加成功后，前端应重新请求查询接口，不应自行拼装记录状态。
- 查询返回的手机号等敏感资料不在本接口暴露；头像和昵称仅用于 CRM 展示。
- 本次新增 `target_avatar` 并将查询接口声明为结构化响应，旧客户端只读取已有字段时保持兼容。

## 错误

| HTTP | 触发条件 | 前端处理 |
| --- | --- | --- |
| `401` | 未登录或登录失效 | 跳转后台登录 |
| `403` | 缺少 `matchmaker.member.read/manage` 权限 | 提示无权限 |
| `404` | 接收会员或被推荐会员不存在 | 刷新会员数据并提示不存在 |
| `409` | 同一日期已存在相同推荐 | 刷新查询列表，避免重复提交 |
| `422` | 参数格式、范围错误或自推荐 | 展示字段校验错误 |

错误响应示例：`{"detail":"该会员今日已在推荐名单中"}`。
