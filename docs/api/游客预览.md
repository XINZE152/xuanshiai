# 游客预览接口（GUEST-PREVIEW-20261115）

> 匿名只读预览，服务小程序游客态浏览。三个接口均**无需登录**、不写任何状态、
> 不个性化（带 token 也不改变结果）。脱敏白名单即响应模型字段集合；
> 候选资格复用共享可见性策略（`app/services/candidate_visibility.py`），
> 平台浏览总开关与按 IP 限流与登录态同一套设施。
>
> 实现：`app/api/routes/public_preview.py` / `app/services/public_preview.py` /
> `app/schemas/public_preview.py`。契约测试：`tests/test_public_guest_preview.py`。

## 共同约定

- 完整 URL 前缀：`/api/v1/public`；Method：GET；Content-Type：application/json。
- 权限：匿名。无 Authorization 要求；**永不返回 401**。
- 限流：每 IP 30 次/分钟（固定窗口，`app/core/redis.py::consume_rate_limit`）。
  超限 429；生产 Redis 不可用时该设施 fail-closed 返回 503。
- 平台开关：`platform_operation.browse_enabled` 与 `sys_access.browse_enabled`
  任一关闭时三个接口统一 403，detail 为维护文案（与登录态发现链路一致）。
- 分页：`page` ≥1 ≤100；`page_size` 默认 6、≤10。
- 所有分页响应含 `is_preview: true`，前端据此标记游客态。

#### 1. 游客推荐名片预览

**基本信息**：用途=游客态首页可浏览的脱敏推荐名片；完整 URL=`GET /api/v1/public/discovery/preview`；是否需要登录=否；所需角色/权限=无；成功状态码=200。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认 | 校验 | 业务含义 |
|---|---|---|---|---|---|---|
| page | query | int | 否 | 1 | ge1 le100 | 页码 |
| page_size | query | int | 否 | 6 | ge1 le10 | 每页条数 |

无请求体。非法示例：`?page=0` → 422；`?page_size=11` → 422。

**返回参数**（`PublicDiscoveryPreviewPage`）：

| 字段 | 类型 | 必返 | 空值含义 | 业务含义 |
|---|---|---|---|---|
| items | PublicPreviewCard[] | 是 | 空数组=无可见候选 | 脱敏名片列表 |
| page | int | 是 | - | 当前页 |
| page_size | int | 是 | - | 每页条数 |
| total | int | 是 | 0=无候选 | 可见候选总数 |
| has_more | bool | 是 | - | 是否有下一页 |
| is_preview | bool | 是 | 恒 true | 游客预览标记 |

`PublicPreviewCard`：

| 字段 | 类型 | 必返 | 空值含义 | 业务含义 |
|---|---|---|---|---|
| user_id | int | 是 | - | 用户 id（详情接口仍需登录，不构成越权通道） |
| nickname | string\|null | 是 | null=未填写 | 脱敏昵称：首字+`**` |
| avatar | string\|null | 是 | null=无头像 | 公开头像路径 |
| gender | int\|null | 是 | null=未填写 | 1 男 2 女 |
| age | int\|null | 是 | null=无生日 | 年龄 |
| residence_display | string\|null | 是 | null=未填写 | 现居地展示文案 |
| education_level | int\|null | 是 | null=未填写/隐藏 | 学历档位（尊重 hide_school） |
| occupation | string\|null | 是 | null=未填写/隐藏 | 职业（尊重 hide_company） |
| mbti | string\|null | 是 | null=未填写 | MBTI 类型 |
| interest_tags | string[] | 是 | 空数组 | 兴趣标签，最多 3 条 |
| certification_tags | string[] | 是 | 空数组 | 认证标签（实名/人脸/学历/单身承诺） |
| is_vip | bool | 是 | - | 是否会员 |
| detail_locked | bool | 是 | 恒 true | 完整资料需登录解锁 |
| is_liked | bool | 是 | 恒 false | 游客无个人关系 |
| is_favorite | bool | 是 | 恒 false | 游客无个人关系 |

**明确不下发**：收入、身高、体重、家乡、距离、自我介绍、问答、匹配分/理由、
在线状态、任何联系方式（手机号/微信）。

**返回示例**：

```json
{
  "items": [
    {
      "user_id": 22, "nickname": "苏**", "avatar": "/storage/uploads/a.webp",
      "gender": 2, "age": 28, "residence_display": "北京市 市辖区",
      "education_level": 4, "occupation": "教师", "mbti": "INFJ",
      "interest_tags": ["阅读", "旅行", "音乐"],
      "certification_tags": ["实名认证"], "is_vip": false,
      "detail_locked": true, "is_liked": false, "is_favorite": false
    }
  ],
  "page": 1, "page_size": 6, "total": 1, "has_more": false, "is_preview": true
}
```

空数据示例：`{"items": [], "page": 1, "page_size": 6, "total": 0, "has_more": false, "is_preview": true}`。

**错误码**：403 平台维护（detail 字符串）；429 限流（见共同约定）；422 参数校验；503 生产 Redis 不可用。

**业务规则**：候选仅含「所有人可见（who_can_see_me=1）+ profile_visibility=all +
资料完整度达标 + 账号活跃 + 未封禁 + 媒体无拒绝/隐藏」的用户；游客无身份，
不套注册身份性别门禁、不套择偶偏好；不写浏览记录、不扣额度。

#### 2. 游客社区动态预览

**基本信息**：用途=游客态可浏览的公开过审动态；完整 URL=`GET /api/v1/public/community/preview`；是否需要登录=否；成功状态码=200。

**请求参数**：同接口 1（page/page_size）。无请求体。非法示例：`?page=abc` → 422。

**返回参数**（`PublicCommunityPreviewPage`）：分页字段同接口 1；`items` 为 `PublicPostPreview`：

| 字段 | 类型 | 必返 | 空值含义 | 业务含义 |
|---|---|---|---|---|
| id | int | 是 | - | 动态 id |
| author_nickname | string\|null | 是 | null=未填写 | 脱敏昵称：首字+`**` |
| author_avatar | string\|null | 是 | null=无头像 | 作者公开头像 |
| content | string | 是 | - | 动态正文（已过审） |
| images | string[] | 是 | 空数组 | 图片，最多 3 张 |
| topic_name | string\|null | 是 | null=无话题 | 所属话题名 |
| like_count | int | 是 | - | 点赞数 |
| comment_count | int | 是 | - | 评论数 |
| created_at | datetime | 是 | - | 发布时间 |

**明确不下发**：视频、位置、学校、家乡、实名状态、作者 user_id、个人互动标记。

**返回示例**：

```json
{
  "items": [
    {
      "id": 101, "author_nickname": "苏**", "author_avatar": null,
      "content": "周末去了植物园", "images": ["/storage/uploads/p1.webp"],
      "topic_name": "同城生活", "like_count": 2, "comment_count": 1,
      "created_at": "2026-11-15T10:00:00"
    }
  ],
  "page": 1, "page_size": 6, "total": 1, "has_more": false, "is_preview": true
}
```

空数据示例：items 为空数组，total=0。

**错误码**：同接口 1。

**业务规则**：仅 `visibility=0`（公开）且作者 `show_posts=1`、`moderation_status=1`、
未删除、作者满足共享可见性策略（guest 视角）的动态；按发布时间倒序；
待审/隐藏/拒绝/仅自己/好友可见动态一律不出现。

#### 3. 游客线下活动预览

**基本信息**：用途=游客态可浏览的报名中活动；完整 URL=`GET /api/v1/public/activities/preview`；是否需要登录=否；成功状态码=200。

**请求参数**：同接口 1。无请求体。非法示例：`?page_size=0` → 422。

**返回参数**（`PublicActivityPreviewPage`）：分页字段同接口 1；`items` 为 `PublicActivityPreview`：

| 字段 | 类型 | 必返 | 空值含义 | 业务含义 |
|---|---|---|---|---|
| id | int | 是 | - | 活动 id |
| title | string | 是 | - | 活动标题 |
| cover | string\|null | 是 | null=无封面 | 封面图 |
| type | string\|null | 是 | null=未分类 | 活动类型 |
| city | string\|null | 是 | null=线上/未填 | 城市 |
| start_time | datetime | 是 | - | 开始时间 |
| end_time | datetime | 是 | - | 结束时间 |
| signup_deadline | datetime\|null | 是 | null=无截止 | 报名截止 |
| max_people | int | 是 | - | 人数上限 |
| current_people | int | 是 | - | 已报名数 |
| price | float | 是 | 0=免费 | 价格 |
| status_text | string | 是 | - | 状态文案（recruiting） |
| description | string\|null | 是 | null=无简介 | 活动简介 |

**明确不下发**：精确地址（address）、我的报名态（my_status/my_status_text）。

**返回示例**：

```json
{
  "items": [
    {
      "id": 9, "title": "周末读书会", "cover": null, "type": "兴趣",
      "city": "北京", "start_time": "2026-11-21T14:00:00",
      "end_time": "2026-11-21T17:00:00", "signup_deadline": "2026-11-20T23:59:59",
      "max_people": 12, "current_people": 5, "price": 0.0,
      "status_text": "recruiting", "description": "一起读一本书"
    }
  ],
  "page": 1, "page_size": 6, "total": 1, "has_more": false, "is_preview": true
}
```

空数据示例：items 为空数组，total=0。

**错误码**：同接口 1。

**业务规则**：仅报名中（status=1）活动；复用 `list_activities(filter_key="recruiting")`，
viewer_id=0 故无个人报名态；报名动作仍走需登录的既有接口。

## 前端接入约定

- 游客态首页/社区/活动页消费以上三接口；未登录**不要**请求需鉴权的
  `/discovery/recommendations`、`/community/posts`、`/ai/capabilities` 等。
- 交互动作（喜欢/申请/聊天/发布/报名/AI）触发登录；登录后切回既有鉴权接口。
- 429 时展示「浏览太频繁，请稍后再试」并退避重试；403 维护态展示维护文案。
