# 红娘说共享字段（NOTE-SHARED-20261111）

管理员端资料扩展接口和小程序红娘工作台接口共同读写 `user_profile.matchmaker_note`，不再把工作台的旧备注表当作红娘说数据源。工作台接口仍使用服务红娘身份和既有会员范围校验，不能使用管理员接口绕过权限。

- `GET /api/v1/matchmaker/workbench/members/{member_id}/note`：用户 Bearer 令牌，无请求体；成功返回 `{"user_id":28,"note":"红娘评价","updated_at":null}`。资料字段为空时 `note` 为 `""`。
- `PATCH /api/v1/matchmaker/workbench/members/{member_id}/note`：用户 Bearer 令牌，JSON 请求体 `{"note":"红娘评价"}`；`note` 为必填字符串，最多 1000 字，空字符串可清空。成功返回同 GET 结构。未登录返回 401，非服务红娘返回 403，会员不存在或不在工作范围返回 404，参数超限返回 422。
- 管理员端仍使用资料扩展接口 `/api/v1/admin/members/profile-ext/{user_id}` 和管理员令牌；该接口与工作台接口操作同一字段。写入均保留各自的审计记录。

旧表 `matchmaker_admin_member_note` 保留作历史记录，不自动覆盖已有资料内容。
