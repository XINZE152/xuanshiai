# 一键刷新 IP / 手机属地接口（A12-属地）

> 首版：2026-10-24（provider 门控骨架）；2026-11-01（离线解析器 + 真实写库落地）；2026-11-04（手机换绑失效 + 审计明细 + 预检脚本）
> 方案：`no upload/docs/一键更新属地-详细修改方案-2026-11-01.md`
> 代码：`app/services/region/`（解析与写库）、`app/api/routes/matchmaker_crm_admin.py`（门控与契约）

## 0. 当前能力（2026-11-04）

- **支持在线 API 与离线解析**：按 IP/手机分别配置 `disabled / offline / api`；当前规划 IP 走阿里云云市场 AppCode、手机走阿里云号码百科 AccessKey + AuthCode。
- **已实现离线解析并写库**：IP → `users.ip_region`（ip2region，**上限为市级**）；手机号 → `users.phone_region`（离线号段表，省+市）。
- **数据文件是外部资产**，不随仓库分发。offline 缺失时接口返回 `503` 并在 `detail` 中指明缺失项，**不写任何数据**（把「未知」写进展示列比留空更有害）。
- **默认只填空**：目标列已有值不覆盖；需覆盖时显式传 `overwrite=true`，并写入 `business_audit_log.before_json` 快照。
- **手机号变更即失效**：用户换绑、微信补绑、后台编辑会员手机号、推广红娘改号后，`phone_region` 置 `NULL`（列存在时），由下一次刷新补齐；不在换绑热路径同步解析。
- **审计留存受影响 id**：只填空与覆盖两种模式都按 500 行切片写 `user_id` 与新旧值，支持按 id 回滚。
- **API 失败可回落离线**：`region_ip_fallback_provider` / `region_phone_fallback_provider=offline` 且离线资产就绪时，API 整体不可用会回落离线；API 未配置不回退，直接 503。
- **上线预检**：`scripts/region_preflight.py` 只读检查 provider、IP 库/绑定、号段表、API 配置、`users` 列与候选数量，不写库、不调用第三方 API；凭证有效性需 canary 验证。
- **不在本接口范围**：管理后台按钮对接、跨系统鉴权（后台为独立 Java 系统）。

## 1. Provider 门控矩阵

按类型配置：`settings.region_ip_provider` / `settings.region_phone_provider`（`Literal["disabled","offline","api"]`，缺省 `disabled`）：

| provider | 行为 | 状态码 | 写库 |
|---|---|---|---|
| `disabled`（缺省） | 拒绝 | `503` | 否 |
| `offline` | 离线解析 + 分批回写（IP 用 ip2region，手机用号段表） | `200`（资产缺失 `503`） | **是** |
| `api` | 阿里云在线解析 + 分批回写 | `200`（未配置 `503`、上游整体失败 `502`） | **是** |

旧版 `region_resolver_provider` 保留兼容映射：`offline` → offline，`real` → api，`mock` → 干跑；按类型 provider 非 `disabled` 时优先。预发/生产环境禁止 `mock`：`config.py` 校验器直接 `raise ValueError`，服务启动即失败。

> API 部分失败不回滚已成功行：返回 `200`，`failed_count` 记录超时/429/5xx/响应格式错误行数；这些行不写库。API 全部失败才 `502`。API 未配置（Endpoint/Key/AuthCode 缺失）不回退离线，直接 `503`。

## 2. 查询属地解析服务状态

**`GET /api/v1/admin/matchmaker/members/region-resolver`**（权限 `matchmaker.member.read`）

只读目录，不查库、不写库；前端据此决定按钮可用性与文案。

| 字段 | 类型 | 说明 |
|---|---|---|
| `provider` | string | 旧版总开关（兼容展示） |
| `ip_provider` | string | `disabled / offline / api` |
| `phone_provider` | string | `disabled / offline / api` |
| `refresh_enabled` | bool | 任一类 provider 非 `disabled` |
| `adapter_implemented` | bool | 任一类当前配置下是否真有可用适配器 |
| `scope` | string | `ALL` / `SCOPED` / `NONE`（由作用域谓词推导） |
| `affects_all` | bool | 作用域是否退化为全库（用于"全部账号"文案） |
| `ip_db_ready` | bool | 离线 IP 库文件与绑定是否就绪 |
| `phone_segment_ready` | bool | 离线号段表是否就绪 |
| `ip_api_ready` | bool | 阿里云 IP API 配置是否完整 |
| `phone_api_ready` | bool | 阿里云号码百科配置是否完整 |
| `db_version` | string? | 离线数据文件标识（文件名@修改日期） |

## 3. 一键刷新

**`POST /api/v1/admin/matchmaker/members/refresh-ip-region`**
**`POST /api/v1/admin/matchmaker/members/refresh-phone-region`**

| 项 | 说明 |
|---|---|
| 权限 | `matchmaker.member.manage` |
| 敏感操作 | Header `Idempotency-Key`（8–128）+ Query `confirm=true`；缺 `confirm` → `428`，缺/非法键 → `422` |
| 覆盖开关 | Query `overwrite`（默认 `false`，只填空） |
| 幂等 | 同键同载荷返回上次结果；同键不同载荷 `409` |

```http
POST /api/v1/admin/matchmaker/members/refresh-ip-region?confirm=true&overwrite=false
Idempotency-Key: refresh-ip-20261101-0001
```

### 响应 `RegionRefreshResult`

```json
{
  "kind": "ip", "provider": "api", "dry_run": false,
  "scanned_count": 749, "updated_count": 0, "skipped_count": 158,
  "unknown_count": 591, "failed_count": 0, "overwrite": false,
  "scope": "ALL", "affects_all": true,
  "adapter_implemented": true, "elapsed_ms": 1830
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `kind` | string | `ip` / `phone` |
| `provider` | string | 本次实际 provider：`offline` / `api` / `mock` |
| `dry_run` | bool | `mock` 下恒 `true` |
| `scanned_count` | int | 作用域内候选行数（源列非空；只填空模式再排除目标列非空行） |
| `updated_count` | int | **属地值真的变化的行数**（见 §4） |
| `skipped_count` | int | 源值不可解析（空、非法、回环/内网/CGNAT、IPv6 未启用） |
| `unknown_count` | int | 送解析但查不到（号段未收录、IP 库无记录、API 无结果），**不写库** |
| `failed_count` | int | API 超时/429/5xx/响应格式错误行数，**不写库**；全部失败时接口返回 `502` |
| `overwrite` | bool | 本次是否覆盖模式 |
| `scope` | string | `ALL` / `SCOPED` / `NONE` |
| `affects_all` | bool | 是否全库 |
| `adapter_implemented` | bool | 适配器是否就绪 |
| `elapsed_ms` | int | 服务端耗时 |

### 错误码

| 状态码 | 场景 |
|---|---|
| `422` | 缺/非法 `Idempotency-Key` |
| `428` | 缺 `confirm=true` |
| `409` | 同键不同载荷；或 `overwrite` 命中行数超 `region_refresh_overwrite_max_rows` |
| `502` | API 超时/5xx/429 重试耗尽且离线兜底不可用，或 API 全部失败 |
| `503` | provider=`disabled`；API 已启用但 Endpoint/Key/AuthCode 未配置；offline 但 IP 库/号段表/绑定缺失；`ip_region`/`phone_region` 列未迁移 |

## 4. 写库语义（联调必须知道）

1. **只填空**：`WHERE id=:id AND (目标列 IS NULL OR 目标列='')`；已有值不动。
2. **`updated_at = updated_at` 显式自赋值**：`users.updated_at` 带 `ON UPDATE CURRENT_TIMESTAMP`，不自赋值会把全表时间刷成同一时刻，污染列表排序与运营判断。
3. **`updated_count` 是「值真的变了」的行数**，不是候选数也不是 affected rows。实现取 `min(affected_rows, 值变化明细数)`：MySQL 对显式 `updated_at` 自赋值仍计 affected，单用 affected 会在覆盖模式虚高。
4. **`updated_count = 0` 是正常结果**：重复刷新、或属地已正确时必然为 0，前端不要提示"失败"。
5. **审计明细**：`business_audit_log.action = member.region.refresh_{ip|phone}`；只填空与覆盖两种模式都记录 `user_id`、旧值、新值，按 500 行切片写，避免单条 JSON 过大；无行变化时只写一条汇总。
6. **API 失败不写库**：`failed_count > 0` 的行保持原值；`failed_count + skipped_count + unknown_count + updated_count` 可能小于 `scanned_count`，因为同一行可能先被解析成功但值未变化（overwrite 模式），前端不要把差额当失败。

## 5. 作用域与降级

- 候选筛选走 D-16 数据作用域（`CurrentMatchmakerAdmin.scope_exists_clause`，唯一实现，路由层不分支档位）；
- `users.deleted_at` 存在时排除软删行；列缺失时不拼守卫（避免 `Unknown column`）；
- 列未迁移时直接 `503`，不做静默降级——`ip_region` / `phone_region` 缺失无法写库；
- IP 与手机的 provider 就绪度互不影响，任一未就绪只影响对应 `kind`；
- API 整体失败且 `REGION_*_FALLBACK_PROVIDER=offline`、离线资产就绪时，回落离线并返回结果；API 未配置不回退，直接 `503`；
- 手机号变更（用户换绑、微信补绑、后台编辑会员、推广红娘改号）时，`phone_region` 置 `NULL`（列存在时）；下一次刷新按新号码补齐，避免列表长期显示旧号码归属地。

| 资产 | 缺省路径 | 配置键 | 说明 |
|---|---|---|---|
| IP 库 v4 | `data/region/ip2region_v4.xdb` | `REGION_IP_DB_PATH` | 离线兜底；开源约 11MB |
| IP 库 v6 | `data/region/ip2region_v6.xdb` | `REGION_IP_V6_DB_PATH` | 预留，当前 IPv6 计入 skipped |
| 号段表 | `data/region/phone_segment.csv` | `REGION_PHONE_SEGMENT_PATH` | 离线兜底；月度更新 |
| 查询绑定 | `app/services/region/vendor/xdbSearcher.py` | — | 官方单文件 binding |
| 阿里云 IP API | 云市场商品 Endpoint/Path | `REGION_IP_API_*` | AppCode 鉴权；Endpoint/Path/字段按商品配置 |
| 阿里云号码百科 | `dytnsapi.aliyuncs.com` | `REGION_PHONE_API_*` | AccessKey + AuthCode + Mask |

```dotenv
# 按类型 provider

REGION_PHONE_API_VERSION=2020-02-17

REGION_PHONE_API_AUTH_CODE=<authcode>
REGION_PHONE_API_MASK=NORMAL
REGION_PHONE_API_ACCESS_KEY_ID=<access-key-id>
REGION_PHONE_API_ACCESS_KEY_SECRET=<access-key-secret>

# 离线兜底
REGION_IP_DB_PATH=/home/xuanshiai/data/region/ip2region_v4.xdb
REGION_IP_CITY_INDEX=2
REGION_PHONE_SEGMENT_PATH=/home/xuanshiai/data/region/phone_segment.csv
REGION_REFRESH_BATCH_SIZE=500
REGION_REFRESH_OVERWRITE_MAX_ROWS=5000
```

> 换数据文件必须核对字段下标：开源 3.x 为 `国家|省份|城市|ISP`（城市下标 2），商用满载版为 `大洲|国家|省份|城市|区县|ISP|...`（下标 3）。下标错会静默取错字段。
