# 个人资料、媒体与择偶要求接口

## 通用约定

- 接口前缀：`/api/v1`
- 除 `GET /profile/tag-options` 和 `GET /users/me/intro-templates` 外，其余接口必须登录
- 已登录接口需要携带 `Authorization: Bearer <access_token>`
- JSON 接口使用 `Content-Type: application/json`
- 上传接口使用 `multipart/form-data`，文件字段名统一为 `file`
- 成功无返回体时状态码为 `204 No Content`
- 错误响应统一格式：`{"detail": "<错误描述>"}`

## 1. 我的页面聚合信息

### 基本信息

- **用途**：服务端聚合我的页面首屏所需摘要数据
- **URL**：`GET /api/v1/users/me/overview`
- **权限**：已登录用户，只能返回当前 Token 对应用户的信息
- **Content-Type**：无请求体
- **成功状态**：`200 OK`

### 请求参数

无请求体。

### 请求示例

```http
GET /api/v1/users/me/overview HTTP/1.1
Authorization: Bearer <access_token>
```

### 返回参数

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `user_id` | integer | 是 | 当前用户 ID |
| `nickname` | string/null | 是 | 当前用户昵称，未设置时为 null |
| `avatar` | string/null | 是 | 头像地址 |
| `account_status` | integer | 是 | 账号状态：`1` 正常、`2` 冻结、`3` 注销 |
| `completion_score` | number | 是 | 资料完整度 0~100 |
| `certification` | object | 是 | 实名认证摘要 |
| `certification.status` | integer | 是 | `0` 未提交、`1` 审核中、`2` 已通过、`3` 未通过 |
| `certification.label` | string | 是 | 状态展示文案 |
| `membership` | object | 是 | 当前有效会员摘要 |
| `membership.is_vip` | boolean | 是 | 当前是否有有效会员 |
| `membership.package_type` | string/null | 是 | 套餐类型，无会员时为 null |
| `membership.expires_at` | datetime/null | 是 | 到期时间，无会员时为 null |
| `unread_notification_count` | integer | 是 | 未读通知数量 |
| `incoming_application_count` | integer | 是 | 待处理的收到申请数量 |
| `outgoing_application_count` | integer | 是 | 待处理的发出申请数量 |
| `match_count` | integer | 是 | 当前有效匹配数量 |
| `visitor_count` | integer | 是 | 去重后的历史访客数量 |
| `favorite_count` | integer | 是 | 当前用户收藏他人的数量 |
| `favorite_received_count` | integer | 是 | 他人收藏当前用户的数量 |
| `superlike_sent_count` | integer | 是 | 当前用户发出的爆灯数量 |
| `superlike_received_count` | integer | 是 | 当前用户收到的爆灯数量 |
| `shortcuts` | object | 是 | 当前账号可用的快捷入口权限 |
| `shortcuts.can_browse` | boolean | 是 | 是否可进入推荐浏览 |
| `shortcuts.can_apply` | boolean | 是 | 是否可发起申请认识 |
| `shortcuts.can_chat` | boolean | 是 | 是否可发起聊天 |
| `shortcuts.can_edit_profile` | boolean | 是 | 是否可编辑资料 |
| `shortcuts.can_manage_media` | boolean | 是 | 是否可管理媒体 |

### 返回示例

**成功响应：**

```json
{
  "user_id": 12,
  "nickname": "小明",
  "avatar": "/storage/uploads/12/avatar.webp",
  "account_status": 1,
  "completion_score": 100,
  "certification": {"status": 2, "label": "已通过"},
  "membership": {"is_vip": false, "package_type": null, "expires_at": null},
  "unread_notification_count": 2,
  "incoming_application_count": 1,
  "outgoing_application_count": 0,
  "match_count": 3,
  "visitor_count": 15,
  "favorite_count": 5,
  "favorite_received_count": 8,
  "superlike_sent_count": 2,
  "superlike_received_count": 4,
  "shortcuts": {
    "can_browse": true,
    "can_apply": true,
    "can_chat": true,
    "can_edit_profile": true,
    "can_manage_media": true
  }
}
```

**无数据时的统计字段：**

```json
{
  "visitor_count": 0,
  "favorite_count": 0,
  "favorite_received_count": 0,
  "superlike_sent_count": 0,
  "superlike_received_count": 0
}
```

### 使用方法与业务规则

- **前置条件**：已登录即可调用，不要求实名或资料完整度
- **统计口径**：`visitor_count` 是去重历史访客总数；`favorite_count` / `favorite_received_count` / `superlike_sent_count` / `superlike_received_count` 是累计计数
- **会员状态**：`membership.is_vip` 仅基于当前有效套餐判断；历史过期会员返回 `{"is_vip": false, "package_type": null, "expires_at": null}`
- **边界场景**：未设置昵称/头像时对应字段为 null；新注册用户所有计数为 0；冻结账户访问返回 `403`

## 2. 固定标签目录

### 基本信息

- **用途**：获取系统标签目录及自定义标签规则，供前端选择器渲染
- **URL**：`GET /api/v1/profile/tag-options`
- **权限**：公开，无需登录
- **Content-Type**：无请求体
- **成功状态**：`200 OK`

### 请求参数

无。

### 请求示例

```http
GET /api/v1/profile/tag-options HTTP/1.1
```

### 返回参数

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `version` | string | 是 | 标签目录版本号，当前 personal-v2 |
| `catalog_revision` | string | 是 | 当前目录内容修订号 |
| `max_tags` | integer | 是 | 合计上限10 |
| `recommended_min` | integer | 是 | 完善度门槛3，非保存门槛 |
| `custom` | object | 是 | 自定义标签规则 |
| `custom.enabled` | boolean | 是 | 是否开放自定义标签 |
| `custom.max_tags` | integer | 是 | 自定义标签独立上限，当前为3 |
| `custom.min_length` / `custom.max_length` | integer | 是 | 单项字符范围，当前为2～10 |
| `custom.category_required` | boolean | 是 | 自定义标签是否必须归入一个当前分区，当前为 true |
| `categories` | array | 是 | 标签分类数组 |
| `categories[].key` | string | 是 | 分类 key，提交 `tag_selections` 时使用 |
| `categories[].label` | string | 是 | 分类展示名称 |
| `categories[].options` | array[string] | 是 | 该分类下可选标签值列表 |

### 返回示例

```json
{
  "version": "personal-v2",
  "catalog_revision": "2026-09-12.1",
  "max_tags": 10,
  "recommended_min": 3,
  "custom": {"enabled": true, "max_tags": 3, "min_length": 2, "max_length": 10, "category_required": true},
  "categories": [
    {"key": "reading", "label": "阅读", "options": ["科幻小说", "推理小说", "逛独立书店", "做读书笔记"]},
    {"key": "film_tv", "label": "影视综", "options": ["纪录片", "悬疑片", "逛电影节", "看院线首映"]},
    {"key": "music", "label": "音乐", "options": ["民谣", "弹吉他", "去看Livehouse", "分享歌单"]}
  ]
}
```

### 使用方法与业务规则

- **调用时机**：生产前端把本目录随包发布，打开编辑页直接渲染；本接口用于其他客户端和目录同步校验
- **提交约束**：旧字段 `interest_tags`、`personality_tags` 和 `tag_selections` 仍只能提交目录值。新字段 `personal_tags` 可混合目录值和最多3个合规自定义标签；存在自定义标签时须同时提交精确的 `custom_tag_categories`
- **前置条件**：无，公开接口

## 3. 查询资料完整度

### 基本信息

- **用途**：查询资料填写完整度及逐项完成状态
- **URL**：`GET /api/v1/users/me/completion`
- **权限**：已登录用户
- **Content-Type**：无请求体
- **成功状态**：`200 OK`

### 请求参数

无。

### 请求示例

```http
GET /api/v1/users/me/completion HTTP/1.1
Authorization: Bearer <access_token>
```

### 返回参数

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `score` | number | 是 | 服务端计算的完整度 0~100 |
| `missing_items` | array[string] | 是 | 未完成项目的展示名称列表 |
| `items` | array | 是 | 逐项完成状态 |
| `items[].key` | string | 是 | 稳定项目 key |
| `items[].label` | string | 是 | 项目展示名称 |
| `items[].weight` | integer | 是 | 项目权重，所有项目权重总和为 100 |
| `items[].completed` | boolean | 是 | 是否已完成 |
| `can_browse` | boolean | 是 | 是否满足推荐浏览门槛 |
| `can_apply` | boolean | 是 | 是否满足申请认识门槛 |
| `can_chat` | boolean | 是 | 是否满足聊天门槛 |

### 返回示例

```json
{
  "score": 57,
  "missing_items": ["体重", "家乡", "相册", "实名认证"],
  "items": [
    {"key": "gender", "label": "性别", "weight": 7, "completed": true},
    {"key": "weight", "label": "体重", "weight": 4, "completed": false},
    {"key": "hometown", "label": "家乡", "weight": 4, "completed": false},
    {"key": "album", "label": "相册", "weight": 8, "completed": false},
    {"key": "avatar", "label": "头像", "weight": 15, "completed": true}
  ],
  "can_browse": false,
  "can_apply": false,
  "can_chat": false
}
```

### 使用方法与业务规则

- **何时调用**：编辑资料后重新查询；进入首页或发起申请前检查门槛
- **权重说明**：各项目权重固定，总和为 100。权重分布如下：

| 项目 | key | 权重 |
| --- | --- | --- |
| 头像 | `avatar` | 15 |
| 自我介绍 | `intro` | 10 |
| 相册 | `album` | 8 |
| 性别 | `gender` | 7 |
| 出生日期 | `birthday` | 7 |
| 所在地区 | `location` | 5 |
| 家乡 | `hometown` | 4 |
| 婚姻状况 | `marriage` | 5 |
| 实名认证 | `realname` | 5 |
| 单身承诺 | `single_pledge` | 1 |
| 兴趣标签 | `personal_tags` | 8 |
| 职业 | `occupation` | 4 |
| 学历 | `education` | 4 |
| 收入 | `income` | 4 |
| 身高 | `height` | 4 |
| 体重 | `weight` | 4 |
| 择偶要求 | `preference` | 3 |
| MBTI | `mbti` | 2 |

- **门槛说明**：推荐浏览还需要手机号绑定；申请认识和聊天还需要 `realname_status == 2`
- **相册完成条件**：只要存在 1 张未删除的相册图片即视为完成，不要求上传 9 张；9 张是最多数量限制
- **家乡完成条件**：同时填写 `hometown_province_code` 和 `hometown_city_code` 即视为完成，区县编码可选
- **边界场景**：新用户 score 较低，`can_browse` / `can_apply` / `can_chat` 均为 false

## 5. 更新个人资料

### 基本信息

- **用途**：部分更新当前用户资料
- **URL**：`PATCH /api/v1/users/me/profile`
- **权限**：已登录用户
- **Content-Type**：`application/json`
- **成功状态**：`200 OK`

### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 规则 | 含义 |
| --- | --- | --- | --- | --- | --- |
| `gender` | body | integer/null | 否 | `1` 或 `2` | 性别；首次写入后不可自行修改 |
| `birthday` | body | date/null | 否 | `YYYY-MM-DD`，须满 18 岁 | 出生日期 |
| `is_married` | body | integer/null | 否 | `1` 未婚、`2` 离异、`3` 丧偶 | 婚姻状态 |
| `height` | body | integer/null | 否 | 140~220 | 身高（厘米） |
| `weight` | body | integer/null | 否 | 40~120 | 体重（公斤） |
| `occupation` | body | string/null | 否 | 最长 128 字符 | 职业 |
| `industry` | body | string/null | 否 | 最长 128 字符 | 行业 |
| `education_level` | body | integer/null | 否 | 1~8 | 学历等级 |
| `income` | body | number/null | 否 | 0~1,000,000 | 月收入（元） |
| `hometown_province_code` | body | string/null | 否 | 最长 32 字符 | 籍贯省份编码 |
| `hometown_city_code` | body | string/null | 否 | 最长 32 字符 | 籍贯城市编码 |
| `hometown_district_code` | body | string/null | 否 | 最长 32 字符 | 籍贯区县编码 |
| `residence_province_code` | body | string/null | 否 | 最长 32 字符 | 居住省份编码 |
| `residence_city_code` | body | string/null | 否 | 最长 32 字符 | 居住城市编码 |
| `residence_district_code` | body | string/null | 否 | 最长 32 字符 | 居住区县编码 |
| `self_intro` | body | string/null | 否 | 最长 500 字符 | 自我介绍 |
| `personal_tags` | body | array[string] | 否 | 0～10个，最多3个自定义项；不能重复、不能为null或与旧标签字段混传 | 兴趣标签统一入口，[]清空 |
| `custom_tag_categories` | body | object | 否 | 与 `personal_tags` 同传；每个自定义标签必须且只能映射到一个当前分区，系统标签不能出现在映射中 | 自定义标签所属分区；无自定义标签时传 {} |
| `interest_tags` | body | array[string] | 否 | 0~5 个，必须来自对应分类的兴趣标签目录；不传表示保持原值 | 兼容兴趣字段，统一参与兴趣标签完善度 |
| `personality_tags` | body | array[string] | 否 | 0~5 个，必须来自 personality 分类；不传表示保持原值 | 兼容性格字段，统一参与兴趣标签完善度 |
| `mbti` | body | string/null | 否 | 16 种标准 MBTI 值之一 | MBTI 类型 |
| `tag_selections` | body | object | 否 | 每分类 1~5 个，标签须来自对应分类；不传表示保持原值 | 扩展分类标签选择，不替代 `interest_tags` 或 `personality_tags` |

### 请求示例

**完整更新示例：**

```json
{
  "gender": 1,
  "birthday": "1995-05-20",
  "is_married": 1,
  "height": 175,
  "weight": 68,
  "occupation": "软件工程师",
  "industry": "互联网",
```

## 8. 媒体上传

### 通用规则

- **请求头**：`Authorization: Bearer <access_token>`，`Content-Type: multipart/form-data`
- **文件字段名**：统一为 `file`
- **成功状态**：`201 Created`
- **响应**：`ProfileMediaResponse` 对象
- **图片格式**：JPG / JPEG / PNG，最大 5MB，最多 2500 万像素
- **视频格式**：MP4，最大 50MB，最长 30 秒
- **处理**：图片统一转换为 WebP 并生成缩略图；视频需要服务端安装 ffprobe

### 媒体返回对象字段

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `id` | integer | 是 | 媒体 ID |
| `media_type` | string | 是 | `avatar` / `background` / `photo` / `video` |
| `file_url` | string | 是 | 文件访问地址 |
| `thumbnail_url` | string/null | 是 | 缩略图地址（视频为 null） |
| `sort_order` | integer | 是 | 排序序号 |
| `is_primary` | boolean | 是 | 是否首图 |
| `duration_seconds` | integer/null | 是 | 视频时长，非视频为 null |

---

### 8.1 上传头像

- **URL**：`POST /api/v1/users/me/avatar`
- **规则**：图片，覆盖旧头像
- **请求格式**：`multipart/form-data`，文件字段名必须是 `file`。头像不能通过 `PATCH /api/v1/users/me/profile` 的 JSON 字段提交；误传 `avatar` 字段会返回 `422`。

#### 请求示例

```bash
curl -X POST "http://127.0.0.1:8000/api/v1/users/me/avatar" \
  -H "Authorization: Bearer <access_token>" \
  -F "file=@avatar.jpg"
```

#### 返回示例

```json
{"id": 101, "media_type": "avatar", "file_url": "/storage/uploads/12/avatar.webp", "thumbnail_url": "/storage/uploads/12/avatar-thumb.webp", "sort_order": 0, "is_primary": true, "duration_seconds": null}
```

#### 错误请求示例

```json
{"detail":[{"type":"extra_forbidden","loc":["body","avatar"],"msg":"Extra inputs are not permitted","input":"..."}]}
```

这是把头像放进资料 JSON 的结果。前端应改为调用上面的 `POST` 接口，并使用 `FormData.append("file", file)`；不要手动设置 `Content-Type`，由客户端生成 multipart boundary。

### 8.4 上传个人视频

- **URL**：`POST /api/v1/users/me/video`
- **规则**：MP4，最多 1 个；已存在视频时新上传覆盖旧视频
- **特殊依赖**：ffprobe（未安装时返回 `503`）

#### 请求示例


### 使用方法与业务规则（媒体上传）

- **前置条件**：登录即可上传，不强制实名
- **图片处理**：服务端自动转换为 WebP 并压缩；EXIF 方向自动校正
- **文件大小**：上传前前端可先压缩；超过限制服务端返回 `413`
- **幂等**：无幂等保护，每次 POST 创建新媒体或覆盖旧媒体
- **ffprobe**：视频接口依赖 ffprobe 检测真实时长和格式，不接受客户端提交的时长参数

## 11. 修改个人昵称

### 基本信息

- **URL**：`PATCH /api/v1/users/me/nickname`
- **权限**：已登录用户，只能修改当前账号昵称
- **Content-Type**：`application/json`
- **成功状态**：`200 OK`
- **说明**：只更新昵称，不会覆盖其他个人资料字段

### 请求参数

| 字段 | 位置 | 类型 | 必填 | 规则 | 含义 |
| --- | --- | --- | --- | --- | --- |
| `nickname` | body | string | 是 | 去除首尾空格后不能为空，长度 1~64 个字符 | 新昵称 |

### 请求示例

```http
PATCH /api/v1/users/me/nickname HTTP/1.1
Host: 127.0.0.1:8000
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json
{
  "nickname": "小明"
}
```

非法示例：

```json
{
  "nickname": "   "
}
```

返回 `422`：

```json
{
  "detail": "昵称不能为空或只包含空格"
}
```

### 返回参数

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `user_id` | integer | 是 | 当前用户 ID |
| `nickname` | string | 是 | 服务端保存后的昵称，已去除首尾空格 |
| `updated_at` | datetime | 是 | 昵称最后更新时间，ISO 8601 格式 |

### 返回示例

```json
{
  "user_id": 12,
  "nickname": "小明",
  "updated_at": "2026-08-05T16:30:00+08:00"
}
```

### 使用方法与业务规则

- 前置条件：已登录并携带有效 `Authorization` Header。
- 修改成功后，可调用 `GET /api/v1/users/me/profile` 或 `GET /api/v1/users/me/overview` 获取最新昵称。
- 重复提交相同昵称是幂等的，返回当前保存结果。
- 空字符串、全空格字符串、超过 64 个字符或非字符串返回 `422`。
- 用户不存在返回 `404`；未登录或 Token 失效返回 `401`；数据库不可用返回 `503`。

## 12. 错误响应

| HTTP 状态码 | 触发条件 | 前端处理建议 |
| --- | --- | --- |
| `401` | 未登录或 Token 无效/过期 | 跳转登录页或刷新 Token |
| `403` | 账号冻结/注销 | 提示用户联系客服 |
| `404` | 媒体不存在或不属于当前用户 | 刷新列表，不展示删除确认 |
| `409` | 性别不可修改（二次提交 gender）、相册已满、视频已存在 | 各场景提示对应文案 |
| `413` | 文件超过大小限制（图片 5MB、视频 50MB） | 提示用户压缩或更换文件 |
| `415` | 文件格式不支持或真实内容无法识别 | 提示支持的格式 |
| `422` | 字段校验失败（标签、MBTI、年龄、排序、时长等） | 展示 `detail` 中的错误描述给用户 |
| `503` | ffprobe 未安装或视频处理不可用 | 提示"服务暂不可用"，展示兜底 UI |
