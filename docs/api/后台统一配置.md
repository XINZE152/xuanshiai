# 后台统一配置接口

版本：v1，日期：2026-09-08

本组接口把平台配置、业务配置和第三方接入配置统一成“配置域快照”。首次读取时幂等创建项目默认值；已有数据库配置不会被默认值覆盖。

#### 查询配置域

**基本信息**：读取指定配置域。URL：`/api/v1/admin/configs/{namespace}`；Method：`GET`；需要登录和红娘后台管理员权限 `platform.config.read`；响应 `application/json`；成功状态码 `200`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验/示例 | 含义 |
| --- | --- | --- | --- | --- | --- | --- |
| `namespace` | path | string | 是 | 无 | `^[a-z][a-z0-9_]{1,63}$`；合法 `platform_basic`，非法 `Platform-Basic` | 配置域编码 |

**请求体示例**：无请求体。

```http
GET /api/v1/admin/configs/platform_basic
Authorization: Bearer <admin-token>
Accept: application/json
```

**返回参数**：

| 字段 | 类型 | 必返 | 空值含义 | 含义 |
| --- | --- | --- | --- | --- |
| `namespace` | string | 是 | 无 | 配置域编码 |
| `name` | string | 是 | 无 | 配置域名称 |
| `description` | string | 是 | 无 | 配置域说明 |
| `version` | integer | 是 | 无 | 当前快照版本，更新时必须原样提交 |
| `config` | object | 是 | 空对象表示暂无业务配置 | 配置内容，字段按配置域定义 |
| `sensitive_keys` | array<string> | 是 | 空数组表示没有敏感字段 | 敏感字段路径或字段名 |
| `updated_by` | integer/null | 是 | null 表示尚未人工修改 | 最后修改管理员 |
| `updated_at` | datetime/null | 是 | null 表示尚未人工修改 | 最后修改时间 |

**返回示例**：

```json
{
  "namespace": "platform_basic",
  "name": "平台基本配置",
  "description": "平台品牌、分享、默认地区和默认头像。",
  "version": 1,
  "config": {"platform_name": "宣誓爱", "slogan": "你的爱值得郑重宣告"},
  "sensitive_keys": [],
  "updated_by": null,
  "updated_at": null
}
```

**使用方法与业务规则**：必须先登录红娘后台；前端进入配置页先调用 GET，再使用返回的 `version` 更新。首次请求会初始化默认配置。公众号、短信、支付密钥只返回 `******`，真实值不得写入日志。配置域不存在返回 `404`。

**错误**：`401` 未登录；`403` 无配置读取权限；`404` 配置域不存在；`422` namespace 格式错误。前端应提示权限或参数错误，不应重试无效参数。

#### 更新配置域

**基本信息**：替换整个配置域快照。URL：`/api/v1/admin/configs/{namespace}`；Method：`PATCH`；需要权限 `platform.config.write`；请求和响应 `application/json`；成功状态码 `200`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验/示例 | 含义 |
| --- | --- | --- | --- | --- | --- | --- |
| `namespace` | path | string | 是 | 无 | `platform_basic` | 配置域编码 |
| `version` | body | integer | 是 | 无 | 大于等于1；必须等于服务端当前版本 | 乐观锁版本 |
| `config` | body | object | 是 | 无 | 必须是完整快照；合法 `{}`，非法缺少必填配置项由对应域规则拒绝 | 新配置内容 |
| `change_summary` | body | string | 是 | 无 | 1-255 字符 | 变更说明和审计摘要 |

**请求体示例**：

```http
PATCH /api/v1/admin/configs/platform_basic
Authorization: Bearer <admin-token>
Content-Type: application/json

{"version":1,"config":{"platform_name":"宣誓爱","slogan":"你的爱值得郑重宣告"},"change_summary":"更新平台宣传语"}
```

非法示例：`{"version":0,"config":{},"change_summary":""}`，返回 `422`。

**返回参数**：同“查询配置域”，其中 `version` 自动加 1，敏感字段仍然脱敏。

**返回示例**：`{"namespace":"platform_basic","version":2,"config":{"platform_name":"宣誓爱","slogan":"新的宣传语"},"sensitive_keys":[],"name":"平台基本配置","description":"平台品牌、分享、默认地区和默认头像。","updated_by":1,"updated_at":"2026-09-08T10:00:00"}`。

**使用方法与业务规则**：整域替换，不支持隐式字段合并；前端必须先 GET。版本不一致返回 `409`，前端应重新读取并合并后再次提交。更新在数据库事务内完成，并写入前后快照审计；重复提交同一旧版本不会重复覆盖。`sensitive_keys` 中的字段不允许提交明文，提交非空明文返回 `422`，真实值必须通过环境变量或密钥管理系统注入；前端可原样提交服务端返回的 `******`。收费、支付、退款、提现配置仍需由对应业务接口做金额和状态校验。当前没有独立发布流程，保存即生效；后续可增加发布状态而不改变读取接口。

**错误**：`401` 未登录；`403` 无修改权限；`404` 配置域不存在；`409` 版本冲突；`422` 参数校验失败或提交了敏感明文；`500` 数据库异常。前端不得把错误响应中的敏感字段展示给用户。

#### 查询配置审计

**基本信息**：查询某配置域的变更记录。URL：`/api/v1/admin/configs/{namespace}/audit-logs`；Method：`GET`；需要权限 `platform.config.read`；成功状态码 `200`。

**请求参数**：`namespace` 为 path，规则同上；`page` 为 query，整数 1-10000，默认 1；`page_size` 为 query，整数 1-100，默认 20。

**请求体示例**：无请求体。

**返回参数**：返回 `items/page/page_size/total/has_more`；`items` 展开字段包括审计 ID、配置域、版本、动作、操作人、变更摘要、修改前 JSON、修改后 JSON、创建时间。审计中的敏感字段当前保存为配置快照，生产环境上线前应将敏感值改为密文或掩码存储。

**使用方法与业务规则**：按配置域倒序分页，空数据返回 `items: []`；只读；审计记录不得删除。

**错误**：`401`、`403`、`422` 与前述接口一致。

### 默认配置域

`platform_basic`、`platform_operation`、`platform_navigation`、`platform_layout`、`platform_permissions`、`platform_content`、`platform_base_data`、`platform_pay`、`wechat`、`miniprogram`、`sms`、`finance`、`merchant`、`short_video`、`matchmaker`、`system`。

其中 `wechat`、`miniprogram`、`sms`、`finance` 的敏感字段仅保留字段结构和脱敏状态，不从线上页面复制真实密钥。
