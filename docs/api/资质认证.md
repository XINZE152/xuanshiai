# 资质认证接口

本模块面向当前登录用户，提供学历、房产、婚姻材料和单身承诺书的提交与状态查询。材料提交只表示进入人工审核，不代表平台已经核验通过。

统一状态：`0` 未提交、`1` 审核中、`2` 已通过、`3` 未通过。单身承诺必须先通过实名认证，且只有后台审核通过后才同步为用户的单身承诺认证标签。

## 查询认证状态

### 基本信息

- URL：`GET /api/v1/users/me/certifications`
- 权限：Bearer 登录用户，仅返回当前账号材料
- Content-Type：无请求体；响应 `application/json`
- 成功状态码：`200`

### 请求参数

无 query 和 body。Header `Authorization: Bearer <access-token>` 必填；非法或过期 Token 返回 `401`。

### 返回参数

顶层固定返回 `education`、`house`、`marriage`、`single_pledge`。每项包含：

| 字段 | 类型 | 必返 | 空值与枚举 | 业务含义 | 示例 |
|---|---|---|---|---|---|
| `kind` | string | 是 | 对应认证类型 | 稳定类型键 | `education` |
| `status` | integer | 是 | `0/1/2/3` | 未提交/审核中/通过/未通过 | `1` |
| `material_submitted` | boolean | 是 | 无 | 是否已有文件或材料 | `true` |
| `material` | string/null | 是 | 未提交为 `null` | 当前用户自己的材料 URL | `/storage/uploads/1/a.webp` |
| `submitted_at` | datetime/null | 是 | 未提交为 `null` | 最近提交时间 | `2026-09-12T08:00:00` |
| `reviewed_at` | datetime/null | 是 | 未审核为 `null` | 最近审核时间 | `null` |
| `fail_reason` | string/null | 是 | 非失败通常为 `null` | 审核不通过原因 | `签名不清晰` |
| `next_action` | string | 是 | 无 | 前端下一步提示 | `等待平台审核` |
| `education` | string/null | 是 | 仅学历项使用 | 提交的最高学历 | `本科` |
| `school` | string/null | 是 | 仅学历项使用 | 毕业学校 | `南京大学` |
| `title` | string/null | 是 | 仅承诺项使用 | 承诺书标题 | `单身承诺` |
| `content` | string/null | 是 | 仅承诺项使用 | 签署时正文快照 | `本人使用网名…` |

### 使用方法与错误

页面进入和 `onShow` 时查询。重复查询只读且幂等，不限次数；客户端应避免高频轮询。空状态仍返回四个对象。`401` 时重新登录；数据库异常返回 `503`，前端保留当前页面并提供重试。

## 提交学历认证图片材料

### 基本信息

- URL：`PUT /api/v1/users/me/certifications/education/material`
- 权限：Bearer 登录用户，只能修改本人材料
- Content-Type：`multipart/form-data`
- 成功状态码：`200`

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验与业务含义 | 合法示例 | 非法示例 |
|---|---|---|---|---|---|---|---|
| `education` | form | string | 是 | 无 | `小学/初中/高中/中专/大专/本科/硕士/博士` | `本科` | `学士` |
| `school` | form | string | 是 | 无 | 去首尾空格后 2–128 字符，毕业学校 | `南京大学` | `A` |
| `file` | form | file | 是 | 无 | 单张 JPG/JPEG/PNG，≤5 MiB、≤2500 万像素；服务端转 WebP | `certificate.jpg` | `certificate.pdf` |

请求示例：

```http
PUT /api/v1/users/me/certifications/education/material HTTP/1.1
Authorization: Bearer <access-token>
Content-Type: multipart/form-data; boundary=...

education=本科
school=南京大学
file=<certificate.jpg>
```

成功响应为完整 `CertificationsResponse`，其中 `education.status=1`、`material_submitted=true`。重复提交会覆盖本人当前学历材料并重新进入审核中；审核中前端应禁止重复按钮，服务端最终以后一次请求为准。

错误：`401` 未登录；`413` 文件超过 5 MiB 或像素过大；`415` 不是可识别的 JPG/PNG；`422` 学历枚举、学校长度或 multipart 字段不合法；`503` 数据库不可用。

## 提交单身承诺手写签名

### 基本信息

- URL：`PUT /api/v1/users/me/certifications/single-pledge`
- 权限：Bearer 登录用户；必须已实名认证
- Content-Type：`multipart/form-data`
- 成功状态码：`200`

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验与业务含义 | 合法示例 | 非法示例 |
|---|---|---|---|---|---|---|---|
| `agreement_version` | form | string | 是 | 无 | 1–32 字符，必须等于服务端当前 `safety_pledge` 版本 | `v1` | `old-v0` |
| `file` | form | file | 是 | 无 | 手写签名 JPG/JPEG/PNG，≤5 MiB、≤2500 万像素 | `signature.png` | 空文件 |

请求示例：

```http
PUT /api/v1/users/me/certifications/single-pledge HTTP/1.1
Authorization: Bearer <access-token>
Content-Type: multipart/form-data; boundary=...

agreement_version=v1
file=<signature.png>
```

服务端根据当前用户昵称和 `G` 编号生成承诺正文快照，记录当前协议版本、签名文件与签署次数。成功后 `single_pledge.status=1`。后台通过后状态变为 `2` 并同步 `users.is_single_pledge=1`；驳回后状态为 `3`、返回 `fail_reason`，用户可重新签署。

前置与防重：先调用 `GET /auth/me` 确认 `realname_status=2`，再调用 `GET /auth/agreements` 获取当前版本。审核中或已通过时重复提交返回 `409`；驳回后可重签。接口不扣费、不消耗额度。

错误：`401` 未登录；`403` 实名未通过；`409` 协议版本过期、正在审核或已通过；`413` 文件过大；`415` 图片格式或内容无效；`422` 表单校验失败；`503` 数据库不可用。

## 兼容接口

- `PUT /api/v1/users/me/certifications/education`：旧版 JSON `{"education":"本科"}`，为旧客户端保留；新版必须使用 `/education/material` 同时提交学校和图片。
- `PUT /api/v1/users/me/certifications/house`：multipart 单图上传，字段 `file`。
- `PUT /api/v1/users/me/certifications/marriage`：JSON `{"is_unmarried":true}`，属于婚姻认证材料，不等同于单身承诺书。

## 后台审核

后台通过 `GET /api/v1/admin/members/auth/commitment-reviews` 和 `education-reviews` 查看材料，通过 `PATCH /api/v1/admin/members/auth/{kind}/{review_id}` 提交 `{"status":1}`（通过）或 `{"status":2,"remark":"原因"}`（未通过）。驳回必须给出原因，操作写入业务审计日志。
