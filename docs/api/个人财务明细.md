# 个人财务明细

任务标识：PERSONAL-FINANCE-HISTORY-20261117。

## 接口

`GET /api/v1/finance/ledger` 查询本人余额账本，`GET /api/v1/finance/expenses` 查询本人支付支出。两者均需 `Authorization: Bearer <token>`，响应为 JSON，成功码 200；无请求体。用户身份只取登录令牌，不能指定其他账户。

| 参数 | 位置 | 类型 | 必填 | 默认 | 规则和含义 |
| --- | --- | --- | --- | --- | --- |
| page | query | 整数 | 否 | 1 | 大于等于 1；例：1，非法：0 |
| page_size | query | 整数 | 否 | 20 | 1–100；例：20，非法：101 |

请求示例：`GET /api/v1/finance/ledger?page=1&page_size=20`，Header 为 `Authorization: Bearer <token>`；无 Body。非法示例：`GET /api/v1/finance/ledger?page=0`。

成功示例：`{"items":[{"id":12,"title":"提现申请","amount":"10.00","direction":"DEBIT","state":"AVAILABLE","source_type":"withdrawal","created_at":"2026-11-17T10:00:00","status":"PENDING_REVIEW"}],"page":1,"page_size":20,"total":1,"has_more":false}`。无数据时 `items` 为空数组，`total` 为 0。

| 返回字段 | 类型 | 含义 |
| --- | --- | --- |
| items | 数组 | 本页记录，必返；无数据为空数组 |
| items[].id | 整数 | 对应账本或订单编号，必返；两种接口编号互不共用 |
| items[].title | 字符串 | 业务名称，必返 |
| items[].amount | 十进制字符串 | 正金额，必返；方向由 direction 表示 |
| items[].direction | 字符串 | `CREDIT` 入账或 `DEBIT` 支出，必返 |
| items[].state | 字符串 | 账本状态，如 `PENDING` 待结算、`AVAILABLE` 可用、`REVERSED` 冲正；必返 |
| items[].source_type | 字符串 | 账本来源或 `payment_order`，必返 |
| items[].created_at | 日期时间 | 业务时间，必返 |
| items[].status | 字符串或 null | 提现审核或订单状态；null 表示无附加状态 |
| page、page_size、total | 整数 | 当前页、每页条数和总数，必返 |
| has_more | 布尔值 | 是否有下一页，必返 |

余额账本包括提现扣减与拒绝/失败退回，状态以服务端真实记录为准。支出只列有支付时间、状态为已支付或已退款、支付方式为微信或余额且渠道不是 mock 的订单；退款订单保留原支付记录，全额退款标记 `REFUNDED`，部分退款标记 `PARTIAL_REFUND`。余额支付只按订单展示一次，不再追加账本支出，避免重复。提现不是消费支出，显示在分成和余额明细。接口按时间和编号降序分页，无写操作或幂等键。

## 提现列表兼容变更

`GET /api/v1/finance/withdrawals` 新增可选 `page`（默认 1，最小 1）和 `page_size`（默认 100，范围 1–100），仍返回 `WithdrawalResponse` 数组。旧客户端不传参数时的行为不变；客户端收到少于 `page_size` 条时表示没有下一页，恰好满页时可继续请求下一页。

错误：401 未登录，422 分页参数不合法，5xx 服务不可用；例如 `{"detail":"请先登录"}`。客户端应显示错误和重试，不用虚构记录替代。
