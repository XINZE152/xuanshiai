# 审核管理接口

所有以下接口均需 `Authorization: Bearer <access_token>`，且当前用户必须拥有 `user_role.role_code=admin,status=1`；非 admin 返回 `403`。

## 实名认证

### `GET /api/v1/admin/realname-reviews`
查询实名待审列表。Query：`page`（默认 1）、`page_size`（默认 20，1-100）、`status`（`1`审核中或`4`人工复核，默认 1）。返回 `items/page/page_size/total/has_more`；item 含 `user_id/nickname/real_name/id_card_masked/realname_status/submitted_at/reviewed_at/fail_reason`。

### `PATCH /api/v1/admin/users/{user_id}/realname/review`
Body：`{"status":2,"reason":null}`。`status`：`2`通过、`3`失败、`4`转人工复核；仅 `realname_status=1` 可审核，否则 `409`。审核人和时间写入审核记录。失败/复核建议填写 `reason`。

## 学历、房产、婚姻认证

### `GET /api/v1/admin/certification-reviews`
查询资质待审列表。Query：`page`、`page_size`、`kind`（`education|house|marriage`，可选）、`status`（`1`审核中，`2`通过，`3`失败，默认 1）。返回分页字段及 item：`user_id/nickname/kind/status/material_submitted/submitted_at/reviewed_at/fail_reason`。

### `PATCH /api/v1/admin/users/{user_id}/certifications/{kind}/review`
Body：`{"status":2,"reason":null}`；`kind` 为学历、房产或婚姻，`status` 为 `2`通过或 `3`失败。材料不存在返回 `404`，非审核中返回 `409`。

## 其他审核权限

举报、举报申诉、社区内容、媒体、聊天消息 `PATCH /api/v1/admin/messages/{message_id}/moderation`、活动报名 `PATCH /api/v1/admin/activity-signups/{signup_id}` 均仅 admin 可执行；原红娘后台令牌不再具备这些审核动作权限。聊天消息列表和活动管理的非审核接口保持原有权限兼容。

错误：`401`未登录或令牌失效，`403`非 admin，`404`资源/材料不存在，`409`状态冲突，`422`参数或枚举错误。

## 举报与内容治理

### `POST /api/v1/security/reports`
普通登录用户提交举报。Body：`target_type`（`user|post|comment|paper_plane|message|user_media|community_media`）、`target_id`（必填）、`type`（动态/评论/纸飞机使用举报原因 ID，消息和媒体可使用文本分类）、`description`（最多 1000 字）、`images`（本人上传证据图片 ID，最多 9 张）。不能举报自己的内容；目标不存在返回 `404`，重复举报返回 `409`。

### `PATCH /api/v1/admin/reports/{report_id}/review`
仅 `admin`。Body：`status`（`1`成立、`2`驳回）、`result`、`action`（`none|hide_content|restore_content|restrict_user|restrict_user_content|dismiss`）。当 `status=1` 且未传 action 时，后端自动封禁：内容举报立即下架对应文字/图片/视频，用户举报冻结账号并将昵称替换为“已封禁用户”、头像清空；`hide_content` 等显式动作仍可用于人工复核。`restrict_user` 只创建用户限制，`restrict_user_content` 同时批量隐藏该用户历史媒体、动态、评论、纸飞机、社区媒体和聊天消息。制裁动作必须提供 `restriction_type`、`restriction_reason_code`，可选 `restriction_ends_at`。

返回 `report_id/status/result/action/content_moderated/restriction_created`。审核人、时间和每类资源批量处置均写入 `business_audit_log`，并通知举报相关用户。

### 申诉兼容与变更记录
`GET /api/v1/admin/report-appeals` 的 `target_type` 支持 `message`、`user_media`、`community_media`；批准针对已下架内容的申诉会恢复资源，且复审必须由不同于原审核人的 admin 执行。
