# 纸飞机资料解锁接口

> 变更记录：2026-11-06（UT-2026-11-02-DOC-02，Q46）新增 `GET /api/v1/paper-plane/profile-unlocks` 解锁记录列表；只返回当前登录用户自己的记录，不返回联系方式或完整资料。

#### 查询本人解锁记录列表

**基本信息**：分页读取当前登录用户解锁过的纸飞机目标资料。URL `GET /api/v1/paper-plane/profile-unlocks`；需要登录；`Authorization: Bearer <access_token>`；响应 `200 application/json`。只读接口，不扣积分、不改变解锁状态。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值/校验 | 含义 |
| --- | --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | Bearer 令牌 | 当前查看者身份 |
| `page` | query | integer | 否 | 默认 `1`，`1~1000`；`0` 为非法 | 页码 |
| `page_size` | query | integer | 否 | 默认 `20`，`1~100`；`101` 为非法 | 每页条数 |

**请求示例**：

```http
GET /api/v1/paper-plane/profile-unlocks?page=1&page_size=20 HTTP/1.1
Authorization: Bearer <access_token>
```

**返回参数**：

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `items` | array | 是 | 解锁记录；无记录时为空数组 |
| `items[].target_user_id` | integer | 是 | 被解锁用户 ID |
| `items[].nickname` | string/null | 是 | 被解锁用户昵称 |
| `items[].avatar` | string/null | 是 | 头像原图 |
| `items[].avatar_thumb` | string/null | 是 | 头像缩略图；无缩略图时回退原图 |
| `items[].age` | integer/null | 是 | 年龄；生日缺失为 null |
| `items[].unlocked_at` | datetime | 是 | 解锁时间 |
| `items[].points_cost` | integer | 是 | 当时实际扣减的积分（历史 80；如后续调价按行返回） |
| `items[].unlock_source` | string | 是 | 解锁来源，如 `paper_plane` |
| `items[].target_available` | boolean | 是 | 目标当前是否可查看；false 仅表示不可再打开，不代表记录无效 |
| `page` | integer | 是 | 当前页码 |
| `page_size` | integer | 是 | 每页条数 |
| `total` | integer | 是 | 当前用户解锁记录总数 |
| `has_more` | boolean | 是 | 是否还有下一页 |

**返回示例**：

```json
{
  "items": [
    {
      "target_user_id": 11,
      "nickname": "小林",
      "avatar": "/storage/uploads/11/avatar.webp",
      "avatar_thumb": "/storage/uploads/11/avatar-thumb.webp",
      "age": 29,
      "unlocked_at": "2026-11-02T10:00:00",
      "points_cost": 80,
      "unlock_source": "paper_plane",
      "target_available": true
    }
  ],
  "page": 1,
  "page_size": 20,
  "total": 1,
  "has_more": false
}
```

**使用方法与业务规则**：

- **前置条件**：已登录；只返回 `viewer_user_id=当前用户` 的记录，不接受 viewer 参数。
- **隐私边界**：不返回手机号、微信号、完整资料或联系方式；`target_available=false` 时不提供任何资料内容。
- **分页**：按 `unlocked_at DESC, id DESC` 排序；无记录返回 `items=[]`、`total=0`、`has_more=false`。
- **幂等/额度**：只读，不扣积分、不写解锁记录、不触发通知。

**错误**：

| 状态码 | 触发条件 | 响应示例 | 前端处理 |
| --- | --- | --- | --- |
| `401` | 未登录/Token 失效 | `{"detail":"请先登录"}` | 回登录页 |
| `422` | `page`/`page_size` 越界 | `{"detail":[...]}` | 修正分页参数 |

#### 查询纸飞机目标用户资料解锁状态

**基本信息**：读取当前登录用户对某个纸飞机聊天对象的资料解锁状态。URL `GET /api/v1/paper-plane/profile-unlocks/{target_user_id}`；需要登录；`Authorization: Bearer <access_token>`；响应 `200 application/json`。服务端只返回匿名、隐私过滤后的资料状态，不返回手机号或微信号。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值/校验 | 含义 |
| --- | --- | --- | --- | --- | --- |
| `target_user_id` | path | integer | 是 | `>=1`，如 `11`；`0` 为非法 | 纸飞机会话中的目标用户 |
| `Authorization` | header | string | 是 | Bearer 令牌 | 当前查看者身份 |

**请求体示例**：无请求体。

```http
GET /api/v1/paper-plane/profile-unlocks/11
Authorization: Bearer <access_token>
```

**返回参数**：

| 字段 | 类型 | 必返 | 含义 |
| --- | --- | --- | --- |
| `target_user_id` | integer | 是 | 目标用户 ID |
| `unlocked` | boolean | 是 | 当前查看者是否已解锁 |
| `points_cost` | integer | 是 | 固定为 80 |
| `balance` | integer | 是 | 查看者当前积分余额 |
| `unlocked_at` | datetime/null | 是 | 解锁时间；未解锁为 null |
| `profile` | object/null | 是 | 已解锁时为隐私过滤资料；未解锁为 null。仅含 `display_name`，联系方式字段永不返回 |

**返回示例**：

```json
{
  "target_user_id": 11,
  "unlocked": false,
  "points_cost": 80,
  "balance": 160,
  "unlocked_at": null,
  "profile": null
}
```

**使用方法与业务规则**：必须先建立纸飞机会话并登录，再调用本接口；解锁状态按 `(viewer_user_id, target_user_id)` 隔离。目标不存在、注销、隐藏、资料未完成或任一方向拉黑时不得读取。读取不会扣分；前端只能把服务端的 `unlocked` 作为权限来源。

**错误**：`401` 未登录；`404` 目标不存在或不可见；`422` 非法路径参数。

#### 解锁纸飞机目标用户资料

**基本信息**：扣除 80 积分并创建一次目标资料查看权益。URL `POST /api/v1/paper-plane/profile-unlocks/{target_user_id}`；需要登录；Headers `Authorization`、`Idempotency-Key`；成功 `200 application/json`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值/校验 | 含义 |
| --- | --- | --- | --- | --- | --- |
| `target_user_id` | path | integer | 是 | `>=1`；`0` 非法 | 目标用户 |
| `Authorization` | header | string | 是 | Bearer 令牌 | 当前查看者 |
| `Idempotency-Key` | header | string | 是 | 1–128 字符；空值或超长非法 | 本次解锁请求幂等键 |

**请求体示例**：无请求体。

```http
POST /api/v1/paper-plane/profile-unlocks/11
Authorization: Bearer <access_token>
Idempotency-Key: unlock-11-20260903-a
```

非法示例：省略 `Idempotency-Key` 返回 `422`；使用同一 key 请求另一个目标返回 `409`。

**返回参数**：字段同查询接口；成功时 `unlocked=true`、`points_cost=80`，`balance` 为扣费后的余额；`profile` 仍不包含真实联系方式。

```json
{
  "target_user_id": 11,
  "unlocked": true,
  "points_cost": 80,
  "balance": 80,
  "unlocked_at": "2026-09-03T09:30:00",
  "profile": {"display_name": "匿名用户", "phone": null, "wechat": null}
}
```

**使用方法与业务规则**：服务端在一个事务内依次锁定查看者账户、检查目标可见性、锁定积分余额和 `(viewer,target)` 权益，然后写一条负数 `user_points` 流水和一条权益记录。自解锁、目标不存在/注销/隐藏、资料未完成、任一方向拉黑均拒绝且不扣分。余额不足返回 `402`。同一查看者重复解锁同一目标不会再次扣分；同一 `Idempotency-Key` 重放返回第一次结果；同一 key 改绑另一目标返回 `409`。并发请求由数据库唯一键和行锁保证至多一次扣分。即使解锁成功，联系方式交换仍须走双方确认的纸飞机交换申请，不得从本接口读取原始手机号或微信号。

**错误**：

| HTTP | 条件 | 响应示例 | 前端处理 |
| --- | --- | --- | --- |
| `401` | 未登录/令牌失效 | `{"detail":"请先登录"}` | 引导登录 |
| `402` | 余额少于 80 | `{"detail":"积分余额不足"}` | 展示余额和充值/任务入口 |
| `403` | 自解锁、不可见、注销、拉黑或受限 | `{"detail":"目标用户当前不可见"}` | 不重试，隐藏资料操作 |
| `404` | 目标用户不存在 | `{"detail":"目标用户不存在"}` | 返回会话列表并提示目标已失效 |
| `409` | 幂等 key 已用于其他目标 | `{"detail":"幂等键已用于其他目标用户"}` | 生成新 key 后再操作 |
| `422` | path 或幂等 key 格式非法 | `{"detail":"请提供 1-128 个字符的 Idempotency-Key"}` | 修正参数 |

**兼容性与变更记录**：新增接口和 `paper_plane_profile_unlock` 表，不修改既有纸飞机消息接口。旧客户端不调用本接口时行为不变；新客户端应在交换微信/电话前先查询并按 `unlocked` 展示门禁。资料表不存联系方式，后续字段扩展必须维持这一边界。
