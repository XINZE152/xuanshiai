## 1. 查询页面显示开关

### 基本信息

| 项 | 值 |
| --- | --- |
| 用途 | 一次性下发前端 71 页显示开关生效值、模块开关、平台运营总开关与 AI 公开基准位，供入口隐藏与页面守卫消费 |
| URL | `GET /api/v1/public/page-switches` |
| 是否需要登录 | **否（匿名）**，游客态可用 |
| 所需角色/权限 | 无 |
| Content-Type | 无请求体；响应 `application/json` |
| 成功状态码 | 200 |
| 限流 | 30 次/60 秒/IP（固定窗口，Redis；与游客预览同档） |

### 使用方法与业务规则

- **前置条件**：无。游客与登录用户均可调用；建议 App onLaunch 拉取 + onShow 节流刷新（≥60 秒）。
- **调用顺序**：无依赖；登录用户另按现有契约调用 `GET /ai/capabilities`。
- **幂等**：只读 GET，天然幂等。
- **频率限制**：30 次/60 秒/IP；超限 429。**前端必须静默处理**（不弹 loading/错误 toast），429/断网/超时 fail-open 到本地缓存或默认全开——后端业务接口门禁仍兜底，不会因开关拉取失败放行已关闭的 AI 接口。
- **生效时延**：管理端 PATCH 后后端 ≤30 秒（TTL 缓存，多 worker 各自刷新）；叠加前端 onShow 节流 60 秒，端到端最坏 ≈90 秒且需用户下次 onShow。
- **状态流转**：开关无状态机；true↔false 随时可切。锚点六页（登录/注册/首页/引导/家长两页）恒 true，管理端写入 false 也不生效。
- **边界场景**：`chat/detail` 为 AI 与普通聊天共用页，其页面开关只控整体；AI 模式可用性由 capabilities 判定。注册表外的路径键（管理端误写）被忽略，以注册表 71 键为准。
- **前端处理建议**：入口按 `pages` 生效值隐藏（含知遇悬浮球/面板动作数组过滤）；71 页 onLoad 守卫；tab 页条目过滤 + 页内占位兜底 switchTab 直达。

### 错误契约

| HTTP | 业务码 | 触发条件 | 前端处理建议 |
| --- | --- | --- | --- |
| 429 | `PUBLIC_PAGE_SWITCHES_RATE_LIMITED` | 同 IP 60 秒内超过 30 次 | 静默 fail-open 到缓存/默认，退避后重试 |
| 405 | — | 非 GET 方法 | 修正调用方式 |
| 500 | — | 未预期服务错误 | 静默 fail-open，不阻断 App |

429 响应示例：

```json
{"detail": {"code": "PUBLIC_PAGE_SWITCHES_RATE_LIMITED", "message": "请求太频繁，请稍后再试", "retryable": true}, "message": "请求太频繁，请稍后再试"}
```

（顶层 `message` 由全局异常处理器自动提升，与游客预览一致。）

### 兼容性

- 新增接口，无旧客户端负担；未升级前端不消费本接口，行为不变。
- `pages` 键集合随后端注册表演进；前端契约测试锁定 71 键快照（2026-11-16），pages.json 变更需前后端同批更新。
- `ai` 块结构复用 `AiCapabilitiesResponse`，与 `/ai/capabilities` 字段一致，未来随其演进。

## 2. 管理端配置域（复用既有接口，无新增路由）

读写走 `GET/PATCH /api/v1/admin/configs/{namespace}`（CurrentMatchmakerAdmin，审计自动记录）：

- `platform_page_switches`：`modules`（10 键）、`pages`（71 键）、`placeholder_text`。默认全开。
- `ai_runtime`：9 个 `*_kill` 布尔键，默认全 false。**只关不开**：kill=true 强制关闭对应 AI 能力（≤30 秒生效，免重启）；kill=false 不能打开 env 开关/生产审批门关闭的功能。
- PATCH 契约（既有 `AdminConfigUpdate`）：必须提交**完整配置域快照** + 读到的 `version`（乐观锁）+ `change_summary`。应急总关停操作序列：
  1. `GET /api/v1/admin/configs/ai_runtime` → 记下 `version` 与 `config`；
  2. 把 `config.master_kill` 置 true，`PATCH /api/v1/admin/configs/ai_runtime`，body `{"version": <读到的版本>, "config": <完整快照>, "change_summary": "应急关停：AI API 到期"}`；
  3. 恢复时同流程置回 false。版本冲突（他人已改）需重读重试。

## 3. 对既有接口的影响

- `GET /ai/capabilities`：响应结构不变；判定新增运行时 kill 判据（master 字段计入 master_kill）。向后兼容。
- 全部 AI/voice 接口：kill 生效时返回既有 `503 AI_FEATURE_DISABLED`，错误契约不变。
