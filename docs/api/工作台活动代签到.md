# 红娘工作台活动代签到

任务标识：WORKSPACE-ACTIVITY-CHECKIN-20261116。

## 代签到

`POST /api/v1/matchmaker/workbench/activity-signups/{signup_id}/check-in`。需服务红娘登录，`Authorization: Bearer <token>`；响应为 `application/json`。无请求体。报名必须处于当前红娘可管理的会员范围（总店超级红娘使用工作台活动列表的范围），且活动在线、审核通过。已取消或未通过的报名不能签到。

| 参数 | 位置 | 类型 | 必填 | 约束与含义 |
| --- | --- | --- | --- | --- |
| signup_id | path | integer | 是 | 大于 0 的报名记录 ID，例如 301；`0` 非法 |

请求示例：`POST /api/v1/matchmaker/workbench/activity-signups/301/check-in`，携带上述认证头，无请求体。

成功 HTTP 200：`{"id":301,"checked_in":true}`。`id` 是报名记录编号，`checked_in` 是签到状态，两者均必返且不为空。重复请求返回相同结果，不重复写审计；首次签到同事务写入审核日志。签到后重新读取列表和统计。操作不提供撤销功能；活动列表提供的电话及资料均来自报名快照，可能为空。

错误：401 未登录，403 未获红娘工作台权限，404 报名不存在、活动不可用或超出权限范围，409 报名取消或未通过，422 编号无效；例如 `{"detail":"报名记录不存在或无权操作"}`。客户端应显示服务端提示，网络异常可重试。

## 列表兼容变更

`GET /api/v1/matchmaker/workbench/activity-signups` 的 `items` 新增可空字段 `phone`（报名电话）、`age`（年龄）、`height`（厘米）、`education`（学历）、`income`（收入描述）和 `marriage_status`（婚姻状态）。旧客户端可忽略新增字段；无资料时返回 null。其余查询参数、权限、分页和响应保持不变。
