#### 管理员新增牵线记录

**基本信息**：后台手工写入一条会员牵线申请结果。完整 URL 为 `/api/v1/admin/matchmaker/match-records`，HTTP Method 为 `POST`，需要红娘后台登录及 `matchmaker.service.manage` 权限，Content-Type 为 `application/json`，成功状态码为 `201`。

**请求参数**：

| 参数名 | 位置 | 类型 | 必填 | 默认值 | 校验规则 | 业务含义 |
| --- | --- | --- | --- | --- | --- | --- |
| `from_love_user_id` | body | integer | 是 | 无 | >=1，必须存在 | 牵线会员 ID |
| `to_love_user_id` | body | integer | 是 | 无 | >=1，必须存在，不能与 `from_love_user_id` 相同 | 被牵线会员 ID |
| `create_time` | body | string/date-time | 是 | 无 | ISO 8601 日期时间 | 牵线申请时间 |
| `complete_time` | body | string/date-time | 是 | 无 | ISO 8601 日期时间，不能早于 `create_time` | 牵线完成时间 |
| `line_status` | body | integer | 是 | 无 | `1` 成功，`2` 失败 | 牵线结果；成功建立双方匹配，失败不建立匹配 |

**请求体示例**：

```http
POST /api/v1/admin/matchmaker/match-records HTTP/1.1
Authorization: Bearer <matchmaker_admin_access_token>
Content-Type: application/json
```

```json
{
  "from_love_user_id": 101,
  "to_love_user_id": 202,
  "create_time": "2026-09-06T09:00:00Z",
  "complete_time": "2026-09-06T10:00:00Z",
  "line_status": 1
}
```

非法示例：`{"from_love_user_id":1,"to_love_user_id":1,"create_time":"2026-09-06T10:00:00Z","complete_time":"2026-09-06T09:00:00Z","line_status":9}`。

**返回参数**：

| 字段 | 类型 | 必返 | 空值含义 | 业务含义 | 示例值 |
| --- | --- | --- | --- | --- | --- |
| `id` | integer | 是 | 无 | 新建 `match_apply` 记录 ID | 88 |
| `from_user_id` | integer | 是 | 无 | 牵线会员 ID | 101 |
| `to_user_id` | integer | 是 | 无 | 被牵线会员 ID | 202 |
| `status` | integer | 是 | 无 | `1` 成功，`2` 失败 | 1 |
| `created_at` | string/date-time | 是 | 无 | 申请时间 | `2026-09-06T09:00:00` |
| `responded_at` | string/date-time | 是 | 无 | 完成时间 | `2026-09-06T10:00:00` |

**返回示例**：

```json
{
  "id": 88,
  "from_user_id": 101,
  "to_user_id": 202,
  "status": 1,
  "created_at": "2026-09-06T09:00:00",
  "responded_at": "2026-09-06T10:00:00"
}
```

**使用方法与业务规则**：调用方必须先取得有效红娘后台 Token，并确认两个会员存在。接口使用现有 `match_apply` 表，不要求先创建服务单。当前没有独立幂等键；服务端以双方及申请时间组合检查重复提交，重复时返回 `409`，因此前端应避免并发重复点击。`line_status=1` 写入双向 `user_match`；`line_status=2` 只写申请结果。接口不自动扣减套餐次数，因为现有额度表尚未接入该业务。历史记录不可通过本接口修改或删除。

**错误**：

| HTTP 状态码 | 触发条件 | 错误响应示例 | 前端处理建议 |
| --- | --- | --- | --- |
| 401 | Token 缺失、过期或无效 | `{\"detail\":\"请先登录红娘后台\"}` | 重新登录 |
| 403 | 缺少 `matchmaker.service.manage` 权限 | `{\"detail\":\"权限不足\"}` | 提示无权限并停止提交 |
| 404 | 任一会员不存在 | `{\"detail\":\"会员不存在\"}` | 重新检索会员 |
| 409 | 相同申请时间的重复记录 | `{\"detail\":\"该牵线记录已存在\"}` | 刷新列表，避免再次提交 |
| 422 | 参数格式、状态或时间顺序不合法 | `{\"detail\":\"牵线完成时间不能早于申请时间\"}` | 在表单中修正字段 |

**兼容性**：新增独立管理员接口，不修改既有公开申请接口及其响应字段；旧客户端不调用该路径时行为不受影响。
