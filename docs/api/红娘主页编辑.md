# 红娘主页编辑

登录红娘使用 `GET /api/v1/matchmaker/workbench/homepage` 读取、`PATCH` 同路径修改自己的公开资料。沿用工作台身份与权限校验，不允许指定其他红娘身份。

PATCH 按需接收 `nickname`（1–64 字）、`slogan`（最多 64 字，可清空）、`specialties`（最多 5 项，不重复）、`introduction`（10–2000 字）、`success_cases`（最多 3 项，每项 `description` 为 1–50 字、`images` 最多 3 张）。不传字段保留原值；案例和标签传空数组可清空。返回保存后的主页，包含 `user_id`、`nickname`、`avatar`、`slogan`、`specialties`、`introduction`、`success_cases`。

昵称更新 `users.nickname` 并同步 `matchmaker_workspace_profile.display_name`；签名和介绍更新入驻申请；标签与案例合并写入申请详情，保留微信及审核字段。公开红娘列表、详情使用相同数据源。操作记录审计并在事务提交后返回。无入驻资料返回 404，字段不合法返回 422。

头像沿用 `POST /api/v1/users/me/avatar`，上传成功即生效。案例图片沿用 `POST /api/v1/matchmaker/workbench/leads/photo`（multipart 文件上传），取得 URL 后随主页案例保存；图片限制及转码沿用现有上传服务。无需新增表或迁移。

前端返回服务红娘页面时重新读取列表。远端 `https://xhztest.xyz` 在 2026-11-02 核对时尚未提供主页与案例图片接口，需要部署本次后端；旧服务读取可回退公开主页，保存失败会明确提示，不写入 Mock。
