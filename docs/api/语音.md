# 语音接口（STT 语音转文字 / TTS 文字转语音）

接口前缀：`/api/v1`。本文件覆盖 3 个 HTTP 语音路径（一次性 WebSocket ticket、STT、TTS）和两个 WebSocket 协议。语音能力一期默认关闭（`ai_voice_enabled=false`）；生产启用需满足三道审批门禁、真实 provider、retention 和凭据要求。

### 变更记录

- 2026-09-27：墨相师实时语音 v2 的单次上限与每日额度改为按本轮会话计。单次上限不再按整条 WebSocket 连接寿命计算，到限仍下发 `error(code=REALTIME_SESSION_LIMIT)` 后关闭连接，客户端可重新开始；每日额度由向下取整改为向上取整（不满 1 分钟记 1 分钟）。错误码、消息结构和配置项名称不变。
- 2026-09-25：新增 `POST /api/v1/voice/ws-ticket`。两个语音 WebSocket 统一使用 60 秒、单次消费的 `ticket`，不再接受长期 access JWT query 参数；本地 `tts/`、`voice/tts/` 音频使用 300 秒 HMAC 签名 URL。
- 2026-09-02：墨相师旅程统一使用 `session_start.mode=moxiang_journey`；旧 `profile_build`、`progress` 和 `session_ready` 协议退役，详情见《墨相师实时整理WebSocket》。
- 2026-08-31：墨相师画像建构 WebSocket 增加双主体阶段切换：新增上行 `subject_switch`、下行 `journey_ready`/`journey_progress`，personal 与 ideal_partner 分别维护 master 会话、草稿、进度与发布状态。
- 2026-08-23：实时对话 WebSocket 增加 `ai_reasoning` / `ai_content` 增量帧，以及上行 `revise_text` / `listen`。`audio_end` 只推转写与回复文本，不再自动推 `tts_audio`；确认前静音，客户端点「听它读」才合成。
- 2026-08-20：新增 `/api/v1/voice/transcribe`（STT 异步转写）和 `/api/v1/voice/synthesize`（TTS 同步合成）；错误统一为 `AiErrorDetail` 形状（含 `request_id`）。

通用请求头（HTTP 接口）：

```http
Authorization: Bearer <access_token>   # 必需
Idempotency-Key: <8-128 位 ASCII>       # transcribe/synthesize 必需
```

通用说明：

- HTTP 语音业务接口需要登录；`/voice/ws-ticket` 只校验登录并检查 Redis，不需要 `Idempotency-Key`。
- `ai_voice_enabled=true` 且生产环境满足 `ai_policy_approved`、`ai_provider_approved`、`ai_retention_policy_version`；生产 provider 不得为 mock。
- ticket 只在 WebSocket 握手前消费一次；握手前还会复查 session 撤销、session 过期和账号状态。Redis/数据库不可用时 WebSocket 以 close `1011` 关闭，ticket 无效、重复或状态无效时以 `1008` 关闭。
- ASR 上传音频在内存中直接调用 Provider，不生成可匿名读取的本地 ASR 文件。
- 本地 TTS 音频路径仅限 `/storage/uploads/tts/` 和 `/storage/uploads/voice/tts/`，返回 URL 已带服务端生成的 `expires`、`user`、`revision`、`signature`；客户端不得删除、替换或自行拼接这些 query 参数，也不要记录完整 URL。外部 Provider 音频 URL 保持原样。
  下载时服务端会重新校验签名中 `user` 对应的账号状态和 `privacy_revision`：撤权、注销、把 `user` 改成其他用户、旧 revision、缺失/篡改/过期签名返回 `403`，数据库状态不可确认返回 `503`，文件已清理返回 `404`；取消注销重新激活也不会恢复旧 URL。
- 错误响应统一为：

```json
{
  "detail": {
    "code": "AI_FEATURE_DISABLED",
    "message": "语音功能当前不可用",
    "request_id": "req_01JXc5...",
    "retryable": false,
    "retry_after_ms": 0
  }
}
```

## §0 WebSocket 一次性 ticket

### 请求

```http
POST /api/v1/voice/ws-ticket
Authorization: Bearer <access_token>
```

无请求体、无 `Idempotency-Key`。成功返回 `200 OK`：

```json
{"ticket":"<one-time-ticket>","expires_in":60}
```

`ticket` 只能用于一次 `/voice/conversation` 或 `/voice/moxiang-master` 握手，签发后
60 秒过期。Redis 不可用返回 `503 AI_TEMPORARILY_UNAVAILABLE`；未登录返回 `401`。
签发 ticket 不代表语音功能已开启，实际 WebSocket/旅程门禁仍在握手或
`session_start` 时执行。

## §1 语音转写（STT）—— 上传音频异步转写

### 请求

```http
POST /api/v1/voice/transcribe
Content-Type: multipart/form-data
Authorization: Bearer <access_token>
Idempotency-Key: portrait-1234567890-abc

audio: <binary file, mp3/wav/m4a, ≤5MB, ≤60s, 16kHz 单声道>
question_field_key: age
```

### 请求参数

| 参数 | 位置 | 类型 | 必需 | 约束 | 说明 |
|---|---|---|---|---|---|
| `audio` | form file | binary | 是 | mp3/wav/m4a, ≤5MB | 音频文件（前端 `VoiceRecorder` 录制参数：mp3/16kHz/单声道/≤60s）|
| `question_field_key` | form field | string | 是 | ≤64 字符 | 画像字段 key（如 `age`/`city_code`），用于 mock fixture 匹配 |
| `Idempotency-Key` | header | string | 是 | 8-128 位 ASCII | 幂等键 |

### 成功响应（202 Accepted）

```json
{
  "task_id": "a1b2c3d4e5f6...",
  "status": "queued",
  "poll_after_ms": 1000
}
```

### 轮询结果

通过 `GET /api/v1/ai/tasks/{task_id}` 轮询任务状态（复用 AI 通用任务接口）。当 `status=succeeded` 时，响应中 `result_payload.transcript` 为转写文本：

```json
{
  "task_id": "a1b2c3d4e5f6...",
  "status": "succeeded",
  "poll_after_ms": 0,
  "result_ref": "a1b2c3d4e5f6...",
  "result_payload": {
    "transcript": "我今年28岁，从事产品设计工作"
  },
  "error_code": null,
  "error_message": null
}
```

### 错误码

| HTTP | code | 说明 | retryable |
|---|---|---|---|
| 400 | `AI_INPUT_INVALID` | Idempotency-Key 格式错误或音频为空 | false |
| 403 | — | 鉴权失败或账号状态不允许 | false |
| 413 | `AI_INPUT_INVALID` | 音频文件超过 5MB | false |
| 422 | `AI_INPUT_INVALID` | 音频内容为空 | false |
| 503 | `AI_FEATURE_DISABLED` | 语音功能未启用 | false |
| 409 | `TASK_IDEMPOTENCY_CONFLICT` | 同 key 不同请求摘要 | false |

## §2 语音合成（TTS）—— 文本转语音同步返回

### 请求

```http
POST /api/v1/voice/synthesize
Content-Type: application/json
Authorization: Bearer <access_token>
Idempotency-Key: portrait-1234567890-abc

{
  "text": "请告诉我你的年龄",
  "locale": "zh-CN"
}
```

### 请求参数

| 参数 | 位置 | 类型 | 必需 | 约束 | 说明 |
|---|---|---|---|---|---|
| `text` | body | string | 是 | 1-500 字符 | 待合成的问题文本 |
| `locale` | body | string | 否 | — | 语言代码（如 `zh-CN`）|
| `voice` | body | string | 否 | 默认 `xiaoyun` | 发音人音色 |
| `speed` | body | number | 否 | 0.5-2.0，默认 1.0 | 语速 |
| `Idempotency-Key` | header | string | 是 | 8-128 位 ASCII | 幂等键 |

### 成功响应（200 OK）

```json
{
  "audio_url": "/storage/uploads/tts/abc123.mp3?expires=<unix>&user=<user_id>&revision=<privacy_revision>&signature=<hmac>",
  "audio_format": "mp3",
  "duration_ms": 3000,
  "expires_at": null
}
```

前端通过 `uni.createInnerAudioContext()` 设置 `src = audio_url` 后 `play()` 播放；必须完整保留服务端返回的 `expires`、`user`、`revision` 和 `signature`，签名最长有效 300 秒。

### 错误码

| HTTP | code | 说明 | retryable |
|---|---|---|---|
| 400 | `AI_INPUT_INVALID` | Idempotency-Key 格式错误或文本为空/超长 | false |
| 403 | — | 鉴权失败或账号状态不允许 | false |
| 403 | `AI_POLICY_DENIED` | 本地 TTS 签发时账号状态不允许 | false |
| 503 | `AI_FEATURE_DISABLED` | 语音功能未启用 | false |
| 503 | `AI_TEMPORARILY_UNAVAILABLE` | 语音服务或本地音频状态查询暂时不可用 | true |
| 503 | `AI_QUOTA_EXCEEDED` | 语音服务请求频率过高 | true |

## §3 稳定错误码总表

| code | HTTP | retryable | 说明 |
|---|---|---|---|
| `AI_FEATURE_DISABLED` | 503 | false | 语音功能未启用或审批门禁未通过 |
| `AI_INPUT_INVALID` | 400/413/422 | false | 输入校验失败（空音频/超大/格式错误/Key 格式）|
| `AI_TEMPORARILY_UNAVAILABLE` | 503 | true | 语音服务暂时不可用（超时/连接/5xx）|
| `AI_QUOTA_EXCEEDED` | 503 | true | 语音服务限流（429）|
| `AI_POLICY_DENIED` | 403/503 | false | 本地 TTS 签发时账号无效为 403；其他语音策略拒绝按网关返回 503 |
| `TASK_IDEMPOTENCY_CONFLICT` | 409 | false | 幂等键已用于不同请求内容 |

## §4 实时半双工语音对话（WebSocket）

#### 实时对话

**基本信息**：墨相「和 AI 对话」沉浸层的半双工实时通道。客户端点麦说话，服务端推 ASR 字幕、流式回复文本；确认前不写画像、不自动外放。客户端先调用 `POST /api/v1/voice/ws-ticket`，再连接 `ws(s)://<host>/api/v1/voice/conversation?ticket=<ticket>`；不再接受长期 access JWT query 参数。Method 为 WebSocket，需要登录，Content-Type 为 JSON 文本帧，成功时连接保持到客户端断开。生产环境 `ai_voice_conversation_enabled` 默认关闭，未开门禁时握手失败（close 1008）。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验 | 业务含义 |
|---|---|---|---|---|---|---|
| `ticket` | query | string | 是 | 无 | `/voice/ws-ticket` 签发的 60 秒一次性凭证；缺失、伪造、过期或重复 ticket 在握手前 close `1008` |
| `type` | body | string | 是 | 无 | 见上行枚举 | 消息种类 |
| `session_id` | body | string | `session_start` 时是 | 无 | 非空会话 id | 本轮对话会话 |
| `field_key` | body | string | 否 | `""` | 画像字段 key | 当前想了解的方面 |
| `data` | body | string | `audio_chunk` 时是 | 无 | base64 PCM | 音频块，不入审计日志 |
| `seq` | body | int | 否 | 无 | 递增序号 | 音频块顺序 |
| `text` | body | string | `revise_text` 时是 | 无 | trim 后非空 | 用户改写后的转写；空串返回 `AI_INPUT_INVALID` |

上行 `type` 枚举：`session_start`、`audio_start`、`audio_chunk`、`audio_end`、`revise_text`、`listen`、`cancel`。

**请求体示例**：

```json
{"type": "session_start", "session_id": "sess1", "field_key": "age"}
{"type": "audio_start"}
{"type": "audio_chunk", "data": "<base64 PCM>", "seq": 1}
{"type": "audio_end"}
{"type": "revise_text", "text": "我住杭州"}
{"type": "listen"}
{"type": "cancel"}
```

非法示例：`{"type": "revise_text", "text": "   "}` → `error.code=AI_INPUT_INVALID`。

**返回参数**：

| 字段 | 类型 | 必返 | 空值含义 | 业务含义 | 示例 |
|---|---|---|---|---|---|
| `type` | string | 是 | 无 | 下行种类 | `ai_content` |
| `text` | string | 字幕/回复帧是 | 空串表示本片无字 | ASR 或模型增量 | `记下了` |
| `field_key` | string | `ai_reply` 是 | 回落到 session 的 field_key | 本轮关注字段 | `age` |
| `audio_url` | string | `tts_audio` 是 | 无此帧 | 仅 `listen` 之后出现；本地 URL 仅为 `/storage/uploads/tts/` 或 `/storage/uploads/voice/tts/`，并带服务端绑定的 `expires`/`user`/`revision`/`signature` | `/storage/uploads/voice/tts/abc.mp3?expires=<unix>&user=<user_id>&revision=<privacy_revision>&signature=<hmac>` |
| `code` | string | `error` 是 | 无 | 稳定错误码 | `AI_INPUT_INVALID` |
| `message` | string | `error` 是 | 无 | 可展示说明 | `改写文本为空` |

下行 `type` 枚举：`partial_transcript`、`final_transcript`、`ai_thinking`、`ai_reasoning`、`ai_content`、`ai_reply`、`tts_audio`、`error`。

**返回示例**：

`audio_end` 之后（无 `tts_audio`）：

```json
{"type": "final_transcript", "text": "我今年28岁，在北京工作"}
{"type": "ai_thinking"}
{"type": "ai_reasoning", "text": "先接住年龄"}
{"type": "ai_content", "text": "记下了，你在哪座城市？"}
{"type": "ai_reply", "text": "记下了，你在哪座城市？", "field_key": "age"}
```

客户端再发 `listen` 后：

```json
{"type": "tts_audio", "audio_url": "/storage/uploads/voice/tts/abc.mp3?expires=<unix>&user=<user_id>&revision=<privacy_revision>&signature=<hmac>", "duration_ms": 2000}
```
**使用方法与业务规则**：

- 前置：已登录；`ai_voice_enabled` 与 `ai_voice_conversation_enabled` 均为 true。生产默认关闭。
- 调用顺序：`session_start` → `audio_start` → 若干 `audio_chunk` → `audio_end`。之后可 `revise_text` 重跑回复，或 `listen` 合成当前回复。
- 实时 WS **不写画像**。抽取结果只留在编排器内存；写入必须由父页确认后走 `submitAnswer`。
- `audio_end` 不再自动 TTS。确认前可以流式生成回复文本，不自动外放。
- `revise_text` 会 bump generation，丢弃旧流，按新文本重跑；不要把新旧回复叠在同一张纸上。
- `cancel` 先 bump generation 再 reset，丢弃在途生成与上一轮回复缓存。
- 幂等：WS 帧不走 HTTP Idempotency-Key。
- 前端：有完整 `ai_reply` 后再提供「听它读」；改字失焦或停顿后发 `revise_text`。

**错误**：

| 场景 | 通道 | code | 前端处理 |
|---|---|---|---|
| 门禁关闭 / 生产未开 | 握手 close 1008 | `AI_FEATURE_DISABLED` | 隐藏实时对话入口 |
| 缺 ticket、ticket 无效/过期/重复，或 session/账号状态无效 | 握手 close 1008 | — | 重新获取 ticket；必要时重新登录 |
| Redis/数据库不可用 | 握手 close 1011 | — | 稍后重试，不复用旧 ticket |
| `revise_text` 空串 / 未 session_start | 下行 `error` | `AI_INPUT_INVALID` | 提示改写后再试 |
| ASR / TTS / 模型暂时失败 | 下行 `error` | `AI_TEMPORARILY_UNAVAILABLE` / `AI_QUOTA_EXCEEDED` | 可重试或改打字 |
| `listen` 时账号撤权、注销或签名上下文失效 | 下行 `error` | `AI_POLICY_DENIED` | 停止播放并重新获取当前会话/音频 |
| `listen` 时无法确认账号状态或隐私修订 | 下行 `error` | `AI_TEMPORARILY_UNAVAILABLE` | 稍后重试，不复用旧音频 URL |

## §5 墨相师双画像建构（WebSocket）

### 双主体连续建构

**基本信息**：墨相师正式画像建构使用 `moxiang_journey` 旅程协议。连接前先调用
`POST /api/v1/voice/ws-ticket`，再连接
`ws(s)://<host>/api/v1/voice/moxiang-master?ticket=<ticket>`；不再接受
`token=<access_token>`。完整消息字段、六维进度和迁移说明见
[《墨相师实时整理 WebSocket》](./墨相师实时整理WebSocket.md)。

一个连接可以切换两个相互隔离的主体：

- `personal`：我的墨相，只写用户自己的性格、恋爱观、关系边界和生活方式。
- `ideal_partner`：愿遇之相，只写用户明确表达并确认的择偶偏好、理想人格与相处期待。

**握手与上行契约**：

| 参数 | 位置 | 类型 | 必填 | 默认值 | 校验/含义 |
|---|---|---|---|---|---|
| `ticket` | query | string | 是 | 无 | `/voice/ws-ticket` 签发的 60 秒一次性凭证；缺失、无效、重复或状态失效时 close `1008` |
| `type` | body | string | 是 | 无 | `session_start`、`subject_switch`、`text_message`、`audio_start`、`audio_chunk`、`audio_end`、`listen`、`revise_text`、`cancel` |
| `mode` | body | `session_start` 时必填 | 无 | 固定 `moxiang_journey`；旧 `profile_build` 返回 `AI_INPUT_INVALID` |
| `subject` | body | `session_start`/`subject_switch` 时使用 | `personal` | `personal` / `ideal_partner` |
| `consentVersion` | body | 否 | `profile-text-v1` | 必须对应当前有效的 `profile_text_extract` 授权 |
| `text` | body | `text_message`/`revise_text` 时必填 | 无 | trim 后 1—2000 字 |
| `clientTurnId` | body | 否 | 服务端生成 | 客户端轮次幂等标识 |
| `data` | body | `audio_chunk` 时必填 | 无 | base64 PCM，单片不超过服务端限制 |

**开始和切换示例**：

```json
{
  "type": "session_start",
  "mode": "moxiang_journey",
  "subject": "personal",
  "consentVersion": "profile-text-v1"
}
```

```json
{"type":"subject_switch","subject":"ideal_partner"}
```

**下行重点消息**：

- `journey_ready`：返回 `session_id`、`subject`、`journey_stage`、`resumed`；重连或切换成功后发送。
- `journey_progress`：返回固定六维的 `overall_percent`、`dimensions` 和 `evidence_count`；不是已发布字段数。
- `extraction_status`：只返回 `subject`、`task_id` 和任务状态，不返回候选正文、证据原文或 provider 输出。
- `confirm_card` / `publish_ready`：沿用画像确认/发布链路；候选必须先经用户确认。
- `partial_transcript` / `final_transcript` / `ai_content` / `ai_reply`：实时语音或文字对话消息。
- `tts_audio`：仅在客户端发送 `listen` 后出现；本地 URL 已带签名，详见下方音频规则。

**语音和实时 v2**：语音功能仍需 `ai_voice_enabled` 与
`ai_voice_conversation_enabled`，否则 `audio_start` 返回 `AI_FEATURE_DISABLED`，文字旅程
仍按当前旅程门禁处理。客户端显式发送 `protocolVersion=2` 且声明
`capabilities.pcmPlayback=true`，并通过实时 provider 门禁后，`journey_ready` 才会附带
`protocol_version` 和 PCM 输入/输出格式；未协商时使用普通半双工消息。

**实时 v2 额度**（`audio_start` 建立本轮会话时检查，默认值见配置）：

| 规则 | 默认 | 触发 | 前端处理 |
|---|---|---|---|
| 单次会话上限 `ai_realtime_session_max_minutes` | 10 分钟 | 下行 `error`，`code=REALTIME_SESSION_LIMIT`，随后关闭 WS | 展示「本次语音已结束，可重新开始」；可再次 `audio_start` |
| 每日额度 `ai_realtime_daily_minutes` | 20 分钟 | 下行 `error`，`code=AI_QUOTA_EXCEEDED` | 展示「今日语音时长已用完，明天再来」，当天不再发起语音 |
| 空闲退出 `ai_realtime_idle_exit_seconds` | 60 秒 | 与单次上限相同，`REALTIME_SESSION_LIMIT` 后关闭 | 可重新开始 |
| 额度存储不可用 | — | 下行 `error`，`code=AI_TEMPORARILY_UNAVAILABLE` | 稍后重试，不把未知用量当成 0 |

计时口径：一条 WebSocket 连接可以先后承载多轮语音。单次上限从本轮会话建立成功时起算，不按连接寿命计；打断后重建上游不重新起算。每日额度在会话结束时按本轮实际时长向上取整累计（4 分 1 秒记 5 分钟，不满 1 分钟记 1 分钟）。从未开麦、或已切到文字输入时不扣额度。Redis 键仍是 `ai:rt-voice:daily:{user}:{yyyymmdd}`，不可用时停止新会话。同一用户同时只占一条会话名额，冲突时 `REALTIME_SESSION_BUSY`。

**主体与任务规则**：

- `personal` 和 `ideal_partner` 分别维护 master 会话、进度、候选和发布状态；切换不会重置另一主体。
- 每轮最终文字或 ASR 转写先持久化再入队 `moxiang_candidate_extract`；partial transcript 永不入队。
- `cancel` 或断线不取消已落库任务；重连通过 `session_start` 恢复 `journey_ready`、进度和待确认卡片。
- 本地 TTS URL 只允许 `/storage/uploads/tts/` 或 `/storage/uploads/voice/tts/`，query 必须保留服务端绑定的 `expires`、`user`、`revision`、`signature`，签名有效期最长 300 秒；撤权、注销、旧 revision、缺签名、篡改或过期返回 `403`，数据库状态不可确认返回 `503`，文件清理后返回 `404`；取消注销重新激活也不会使旧 URL 恢复访问。
- 客户端不得记录 ticket、access token 或带签名的音频 URL；Redis/数据库不可用时握手 close `1011`。

**错误与前端处理**：

| 场景 | 通道 | code / close | 前端处理 |
|---|---|---|---|
| ticket 缺失、无效、过期、重复或 session/账号状态无效 | 握手 | close `1008` | 重新获取 ticket；必要时重新登录 |
| Redis/数据库不可用 | 握手 | close `1011` | 稍后重试，不复用旧 ticket |
| 旧 mode、非法 subject、空/过长文本 | 下行 `error` | `AI_INPUT_INVALID` | 修正请求 |
| 授权缺失或撤回 | 下行 `error` | `AI_CONSENT_REQUIRED` | 引导重新授权 |
| 旅程/provider/ASR 暂时失败 | 下行 `error` | `AI_TEMPORARILY_UNAVAILABLE` | 保留已有进度，稍后重试 |
| 旅程或语音门禁关闭 | 下行 `error` 或音频分支错误 | `AI_FEATURE_DISABLED` | 继续使用允许的文字路径，不回退旧协议 |
| `listen` 时账号撤权、注销或旧 revision | 下行 `error` | `AI_POLICY_DENIED` | 停止播放并重新获取当前会话/音频 |
| `listen` 时无法确认账号状态或隐私修订 | 下行 `error` | `AI_TEMPORARILY_UNAVAILABLE` | 稍后重试，不复用旧音频 URL |
