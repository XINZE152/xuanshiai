# 聊天联系方式交换

## 变更记录（2026-11-02）

**变更前**：请求 payload 在待确认时直接返回，PHONE 不自动取绑定号码。

**变更后**：PHONE/WECHAT 只有 ACCEPTED 返回 `payload.contact_value`，其他状态为 null；PHONE 从发起人账号取绑定号码，忽略客户端输入；WECHAT 只存校验后的 contact_value。其他类型不变，无数据库迁移。

迁移：旧客户端不能再读取待确认联系方式，须等对方同意后重新查询。历史无 contact_value 的 PHONE 记录需重新发起。前后端配套部署；仅前端过滤无法消除旧服务在 HTTP 响应里提前交付联系方式的问题。

## 基本信息

全部路径前缀 `/api/v1`，Bearer 登录；沿用 `_session` 的参与人、账号限制、匹配及拉黑校验。`session_id` 必须来自 GET /chat/sessions，不是对方用户 ID 或登录会话 ID。请求/响应为 application/json。当前前端仅开放普通用户，不开放父母代操作。

本功能分享的是**发起人的联系方式**，双方可在接收人同意后查看；不会自动分享接收人的联系方式，需要时反向发起。

## 发起请求

`POST /api/v1/chat/sessions/{session_id}/requests`，成功 201。

| 参数 | 位置 | 类型 | 必填/默认 | 规则和用途 |
|---|---|---|---|---|
| Authorization | header | string | 是 | Bearer access_token |
| session_id | path | integer | 是 | ≥1，当前用户有权访问的聊天会话 |
| request_type | body | string | 是 | 本功能 WECHAT/PHONE；既有 ANSWER_EXCHANGE/LOVE_MODE 不变 |
| payload | body | object/null | 否/null | WECHAT 必须提供 contact_value；PHONE 忽略客户端输入，由服务端生成 |
| payload.contact_value | body | string | WECHAT 必填 | 微信号去首尾空格后6–20位，字母开头，仅字母数字下划线短横线 |
| expire_hours | body | integer | 否/48 | 1–168，请求有效小时数 |

```http
POST /api/v1/chat/sessions/71/requests
Authorization: Bearer <access_token>
Content-Type: application/json

{"request_type":"WECHAT","payload":{"contact_value":"example_wx"},"expire_hours":48}
```

手机号使用相同 URL/Headers，Body 为 `{"request_type":"PHONE"}`，服务端读取当前账号11位大陆绑定手机号。非法示例：`{"request_type":"WECHAT","payload":{"contact_value":"123"}}` → 422；未绑定号码发起 PHONE → 422。

同一发起人/会话/类型已有未过期 PENDING 请求时409。前端操作时禁用重复点击；虽携带命令标识，当前接口**不承诺 Idempotency-Key 重放返回同一结果**。超时先 GET 查询再决定重发，不自动盲重试。无新增专属频率限额，无积分/次数扣减。

## 查询请求

`GET /api/v1/chat/sessions/{session_id}/requests`，成功200。仅 Authorization 和 session_id，约束同上；无请求体、无 query 参数。

```http
GET /api/v1/chat/sessions/71/requests
Authorization: Bearer <access_token>
```

返回数组（共用结构见下），无数据为 `[]`。无分页，ID 倒序；仅当前会话参与人的记录。前端仅选 PHONE/WECHAT，不混入问答或恋爱模式请求。查询时服务端把过期 PENDING 置为 EXPIRED。非法示例 session_id=0 →422；他人会话无权读取。

## 同意、拒绝、撤回

`PATCH /api/v1/chat/session-requests/{request_id}`，成功200。

| 参数 | 位置 | 类型 | 必填/默认 | 规则和用途 |
|---|---|---|---|---|
| Authorization | header | string | 是 | Bearer access_token，仍有会话访问权 |
| request_id | path | integer | 是 | ≥1，POST/GET 返回的请求 ID |
| action | body | string | 是 | ACCEPT 同意、REJECT 拒绝、WITHDRAW 撤回 |

```http
PATCH /api/v1/chat/session-requests/81
Authorization: Bearer <access_token>
Content-Type: application/json

{"action":"ACCEPT"}
```

非法示例 `{"action":"accept"}` →422。只有接收人可 ACCEPT/REJECT，只有发起人可 WITHDRAW；必须未过期 PENDING。行锁保护并发处理，重复处理/过期409。本轮 UI 提供同意和拒绝，未新增撤回入口。失败不得在客户端变为已确认。

## 共用返回结构

POST/PATCH 返回单个对象，GET 返回对象数组，无 data 包装。

| 字段 | 类型 | 必返 | 含义/空值 |
|---|---|---|---|
| id | integer | 是 | 请求 ID |
| session_id | integer | 是 | 聊天会话 ID |
| requester_id | integer | 是 | 发起人 ID |
| responder_id | integer | 是 | 接收人 ID |
| request_type | string | 是 | PHONE/WECHAT；GET 也可能包含原有其他类型 |
| payload | object/null | 是 | 联系方式仅 ACCEPTED 非空；历史无值可为 null |
| payload.contact_value | string | payload 非空时 | 发起人的绑定手机号或填写的微信号，不得写日志 |
| status | string | 是 | PENDING/ACCEPTED/REJECTED/WITHDRAWN/EXPIRED |
| expire_at | datetime/null | 是 | 到期时间；null 为无到期值 |
| responded_at | datetime/null | 是 | 处理时间；未处理 null |
| created_at | datetime | 是 | 创建时间 |

创建成功：

```json
{"id":81,"session_id":71,"requester_id":1,"responder_id":2,"request_type":"WECHAT","payload":null,"status":"PENDING","expire_at":"2026-11-04T10:00:00","responded_at":null,"created_at":"2026-11-02T10:00:00"}
```

确认成功（随后双方 GET 得到相同结果）：

```json
{"id":81,"session_id":71,"requester_id":1,"responder_id":2,"request_type":"WECHAT","payload":{"contact_value":"example_wx"},"status":"ACCEPTED","expire_at":"2026-11-04T10:00:00","responded_at":"2026-11-02T10:05:00","created_at":"2026-11-02T10:00:00"}
```

## 错误和边界

| HTTP | 触发条件 | 客户端处理 |
|---|---|---|
| 401 | 未登录/登录失效 | 使用既有续期或登录流程 |
| 403 | 非会话参与人、非对应操作人、拉黑或账号限制等 | 停止操作、不显示联系方式 |
| 404 | 会话/请求不存在 | 提示不可用并刷新 |
| 409 | 待确认请求重复、已处理、过期 | 保留失败提示，重新查询，不能假装成功 |
| 422 | path/body 校验失败、微信号非法、未绑定有效手机号 | 修正输入或先绑定号码 |

业务错误示例 `{"detail":"同类型请求正在等待处理"}`，无新增业务错误码；Schema 验证错误为 FastAPI detail 数组。联系方式不进入通知 payload，通知只含请求类型/状态。聊天访问权限失效后仍由服务端拒绝查询和处理。
