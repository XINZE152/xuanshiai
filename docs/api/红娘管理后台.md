# 红娘管理后台接口

基础前缀为 `/api/v1`。除上传接口使用 `multipart/form-data` 外，均使用 `application/json`。所有接口需要红娘后台 Token：`Authorization: Bearer <matchmaker-admin-access-token>`。管理权限由服务端校验，普通红娘按账号的数据范围过滤。

## 基础 CRUD

### 红娘列表

**基本信息**：`GET /api/v1/admin/matchmakers`；需要登录；权限 `matchmaker.manage`；响应 `application/json`；成功 `200`。

**请求参数**：`page` query integer，默认 `1`，最小 `1`；`page_size` query integer，默认 `20`，范围 `1..100`；`keyword` query string，可选，最长 `100`，匹配称呼、账号、手机；`store_id` query integer，可选，`>=1`；`commission_level_id` query integer，可选，`>=1`；`locked` query boolean，可选。非法示例：`page=0`。

**请求示例**：

```http
GET /api/v1/admin/matchmakers?page=1&page_size=20&keyword=张&locked=false
Authorization: Bearer <access-token>
```

无请求体。

**返回参数**：`items[]` 包含 `id/avatar/display_name/username/store_id/store_name/role_tag/role_label/phone/wechat/commission_level_id/commission_level_name/commission_rate/success_count/commission_amount/locked/visible/description/created_at/updated_at`；`role_tag` 为 `super|normal`；`locked` 为是否禁止平台登录；`visible` 为是否在 C 端展示；`page/page_size/total/has_more` 为分页信息。

**返回示例**：

```json
{"items":[],"page":1,"page_size":20,"total":0,"has_more":false}
```

**使用方法与业务规则**：关键词和筛选条件可组合；空结果返回空数组；数据范围由账号的 `SELF/STORE/ORGANIZATION/ALL` 服务端执行；不会返回密码。

**错误**：`401` Token 无效；`403` 无权限；`422` 参数非法；`500` 数据库查询失败。错误格式为 `{"detail":"错误说明"}`。

### 新增、详情、编辑、删除

`POST /api/v1/admin/matchmakers`、`GET /api/v1/admin/matchmakers/{id}`、`PUT /api/v1/admin/matchmakers/{id}`、`DELETE /api/v1/admin/matchmakers/{id}`。

新增请求字段：`avatar` 图片 URL；`display_name` 1-32 字；`username` 3-64 位字母数字及 `_.-`；`phone` 至少 11 位数字；`wechat` 最长 64；`store_id`、`commission_level_id` 为正整数；`role_tag` 为 `super|normal`；`description` 最长 2000；`password` 8-128 位；`visible` 默认 `true`。编辑字段均可选，密码修改后旧密码立即失效。成功状态分别为 `201/200/200/200`。

删除为软删除；存在客源或牵线记录时返回 `409`，必须先转移或处理关联数据。账号或手机号重复返回 `409`；门店、分成级别不存在或已停用返回 `422`。

## 状态、权限和业务接口

### 状态开关

`PATCH /api/v1/admin/matchmakers/{id}/lock` 请求体 `{"locked":true}`；`PATCH /api/v1/admin/matchmakers/{id}/visibility` 请求体 `{"visible":false}`。成功返回最新红娘对象。锁定会同时停用后台账号、撤销登录能力；解锁恢复账号状态。重复提交是幂等的。

### 菜单权限

`GET /api/v1/admin/menus/tree` 返回启用菜单树；`GET /api/v1/admin/matchmakers/{id}/permissions` 返回 `{"matchmaker_id":1,"menuIds":[1,2]}`；`PUT /api/v1/admin/matchmakers/{id}/permissions` 请求体 `{"menuIds":[1,2]}`，覆盖保存权限。菜单 ID 不存在返回 `422`。

### 工作汇报和报表

`GET /api/v1/admin/matchmakers/{id}/work-report?from=2026-09-01&to=2026-09-06` 返回新增客源、牵线次数、成功数、分成金额、跟进记录数和当前分配会员数。`GET /api/v1/admin/matchmakers/{id}/report` 返回工作汇报、转化漏斗、月度趋势和成功率。日期范围闭区间，最长 367 个自然日，倒置或超范围返回 `422`。

### 海报和免登

`POST /api/v1/admin/matchmakers/{id}/poster` 返回 `url` 和二维码内容；当前返回可供前端异步生成/展示的海报资源标识。`POST /api/v1/admin/matchmakers/{id}/platform-token` 创建真实后台会话并返回短期 `access_token`、`refresh_token`、`expires_in` 和 `jump_url`，仅管理员可调用，不记录明文密码。

### 教程和字典

`GET /api/v1/admin/matchmakers/tutorial` 返回教程标题、图文内容和可选链接；`GET /api/v1/admin/dict/commission-levels` 返回启用的分成级别及比例；`GET /api/v1/admin/dict/stores` 返回门店字典。

### 上传头像

`POST /api/v1/admin/common/upload` 使用 `multipart/form-data` 字段 `file`，支持 JPG/JPEG/PNG，最大 5MB，服务端校验图片内容并转 WebP；成功 `201` 返回 `url/content_type/size/purpose`。空文件返回 `422`，格式不支持返回 `415`，超限返回 `413`。
